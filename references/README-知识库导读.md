# 易学研究 · 硕士级知识库

> 一套关于中国传统术数（八字、紫微斗数、周易卦象与筮法、风水堪舆、择日奇门等）的
> **结构化、可计算、带批判**的学习与研究资料。
> 定位：**民俗文化与知识史研究**，不是预测服务。

---

## 一、这是什么

本知识库把中国传统"术数"当作一个**有内部逻辑、有历史、有技术成分的知识系统**来研究，目标是达到硕士研究生层次的三条标准：

| 标准 | 具体含义 | 检验方式 |
|---|---|---|
| **能精确复现** | 给定生辰/坐向，能手工或编程排出四柱、大运、紫微十二宫、六爻卦盘、飞星盘 | 卷二排盘题零错误；单元测试全过 |
| **能说明来源与分歧** | 每个概念能说出出处、流派与异说 | 能指出庚干四化、子时换日、二十四山阴阳等分歧 |
| **能批判性定位** | 区分系统内自洽与外部有效，知道边界、偏差与法律风险 | 卷三论述题；能设计一个可证伪的检验 |

**三条缺一不可**：只会排盘是技工，只会批判是不懂装懂。

> 主修不必四门全修。建议选 2 门精修（各 6 学分），其余作通识。硕士的"专"比"全"重要。
>
> **为什么加"批语写作"**：排盘是编码，批语是输出。只会排盘的人能算出答案却不会说话，只会说话的人无据可依。**批语训练是把两者接起来的唯一环节**，也是这门学问里最容易伤人、最需要伦理约束的环节（见 11 篇第八章）。

### 3.2 必读书目（分层）

**第一层：现代学术研究（先建立问题意识）**

- 李零《中国方术正考》《中国方术续考》
- 江晓原《天学真原》《星占学与传统文化》
- 顾颉刚《秦汉的方士与儒生》
- 王其亨等《风水理论研究》

**第二层：原典**

- 易：《周易正义》（王弼注、孔颖达疏）、《周易本义》（朱熹）、高亨《周易古经今注》
- 命理：《渊海子平》《三命通会》《滴天髓》（任铁樵注）《子平真诠》《穷通宝鉴》
- 紫微：《紫微斗数全书》《紫微斗数全集》、王亭之《中州派紫微斗数》
- 风水：《葬书》《撼龙经》《疑龙经》《雪心赋》《地理五诀》、蒋大鸿《地理辨正》、沈竹礽《沈氏玄空学》
- 择日：《协纪辨方书》

**第三层：专题与工具**

- 陈遵妫《中国天文学史》（历法部分）
- 张培瑜《三千五百年历日天象》（历日换算工具书）
- 开源库：`lunar-python`、`sxtwl`、`iztro`、`tyme4j`

### 3.3 考核方式

1. **闭卷笔试**：09 篇试卷，150 分钟。
2. **排盘实操**：给 10 个随机生辰，要求 100% 排对（四柱、大运、紫微主星、六爻装卦）。
3. **文献报告**：精读一部原典，写 5000 字版本与思想述评。
4. **批判报告**：选一个术数命题，设计可证伪检验方案。
5. **专题论文**（可选）：把术数当史料，做一个历史/社会学题目。

## 五、使用约定

1. **术语**：一律用传统术语，首次出现给现代解释。
2. **分歧**：凡流派有异，写明"一说……另一说……"，不强行统一。
3. **引用**：古籍注明书名与注家；现代研究注明作者与出处；无法核实的标"待考"。
4. **案例**：所有命例/宅例均为**方法演示**，不构成对真实个人的预测断言。
5. **禁止**：医疗、投资、婚姻强制、灾祸恐吓类断语（详见 08 篇）。
6. **批语**：凡书面判断一律标明断语级别（确断/倾向/或然/不可断）；寿夭、疾病诊断、刑狱与投资指令**三不批**；每条建议须可执行、可停止（详见 11 篇第八章、12 篇各例）。
