## G. 批语与评点（→ 11、12、13）

| 术语 | 定义 |
|---|---|
| 批语 | 命理师（或其他术数从业者）针对具体盘面写下的书面判断与建议，以**有据、分级、可执行**为体 |
| 批命 / 运程书 | 批语的传统称谓；"运程书"多指逐年逐月的长篇 |
| 盘批 / 卦批 / 宅批 | 按对象分类的批语：批八字紫微盘、批六爻卦、批宅 |
| 五段式 | 批语标准结构：缘起—总纲—分论—行运—结语 |
| 总批 / 分论 / 逐句批 | 分层评点的三个层次（借自评点传统） |
| 象—据—断 | 批语的最小论证单元：盘面之象 → 依何规则 → 得何结论 |
| 四级断语 | 确断（盘面必得）、倾向（有据未说死）、或然（须应期）、不可断（越界拒答） |
| 铁口直断 | 不留余地的断言，传统视为"本事"，现代视为风险与不诚实 |
| 活看 / 留白 | 只写盘所能支撑的，其余不写；传统笔法，亦是学术纪律 |
| 象喻 | 以物喻人的笔法（如"无鞘之刀""弱身担重杀"） |
| 转语 | 断语之间的转折与缓冲（"然""所虑者""所幸"） |
| 春秋笔法 | 措辞隐含褒贬与轻重的写法 |
| 三不批 | 不批寿夭、不批生死疾病诊断、不批刑狱与投资指令 |
| 坏批语十病 | 模板化、堆术语、无据断、恐吓、讨好、越界、含糊、抄书、卖弄、无建议 |
| 改稿 | 拿一份坏批语逐句改写成合格批语，是最有效的训练法 |
| 命书体例 | 传统命书（《渊海子平》《三命通会》等）的行文体例 |
