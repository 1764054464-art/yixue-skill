# 04a 周易卦象（上）：经传源流、象数体系与筮法

> 本篇处理《周易》"经"与"传"两个层面：前者是六十四卦卦爻辞构成的占筮手册，后者是战国至汉初逐步形成的解释系统。

## 一、源流：从卜筮到经传

### 1.1 卜与筮：两条并行的决策技术

先秦的"预测"技术至少有两条主线，性质不同，不可混为一谈：

| 项目 | 龟卜（卜） | 蓍筮（筮） |
|---|---|---|
| 材料 | 龟腹甲、牛肩胛骨 | 蓍草（或竹策、木棍） |
| 操作 | 钻凿、灼烧，观兆坼（"卜"字即兆纹之象） | 按定数分揲计数，得数成爻 |
| 输出 | 兆象（无固定文本系统） | 卦画与卦爻辞（有固定文本系统） |
| 记录 | 甲骨卜辞（"王占曰……"） | 卦爻辞、《左传》《国语》筮例 |
| 文献依据 | 殷墟甲骨、周原甲骨 | 《周礼·春官·大卜》《系辞上》"大衍之数"章 |

《周礼·春官·大卜》："掌三兆之法……掌三易之法……掌三梦之法。"卜、筮、梦三者并列，说明在制度层面它们是并列的官职技术。**关键差异**：卜兆没有符号化文本，筮则把结果编码为六爻卦画，因而可以积累、比较、解释，最终文本化为"经"。这是《周易》能成为哲学文本的技术前提。

《左传·僖公十五年》记韩简之言："龟，象也；筮，数也。物生而后有象，象而后有滋，滋而后有数。"这是先秦人对卜、筮差异最清楚的概括：卜重象，筮重数。

### 1.2 三易：《连山》《归藏》《周易》

《周礼·春官·大卜》："掌三易之法，一曰《连山》，二曰《归藏》，三曰《周易》。其经卦皆八，其别皆六十有四。"这是"三易"说最可靠的制度性记载。汉唐注疏的通行解释：

| 三易 | 首卦 | 时代/作者（旧说） | 郑玄《易赞》《易论》 | 实物证据 |
|---|---|---|---|---|
| 《连山》 | 首艮 | 夏易，神农或夏后氏 | "连山者，象山之出云连连不绝" | 无确证出土；传世辑佚不可尽信 |
| 《归藏》 | 首坤 | 商易，黄帝或殷人 | "归藏者，万物莫不归藏于其中" | 王家台秦简《归藏》残简（1993，湖北江陵王家台15号秦墓） |
| 《周易》 | 首乾 | 周易，文王、周公 | "周易者，言易道周普，无所不备" | 帛书、阜阳简、上博简、清华简等大量实物 |

史学检讨三点：

1. "三易"是否真是三个独立朝代的官书，还是战国秦汉间人对"易类文献"的追认分类，学界无定论。李学勤等倾向于认为三代各有筮书而彼此有因革；亦有学者（如部分疑古派）认为《连山》《归藏》之名晚出。
2. **王家台秦简**（《文物》1995年第1期公布）出土约 800 枚残简，内容为卦画加简短语辞，卦名多与今本《归藏》佚文相合，是"《归藏》确曾存在"的最强实物证据。但整理者与部分学者（如李学勤）认为其性质当为"易占"类竹书，是否为《周礼》所称《归藏》仍可讨论。
3. 《连山》至今无出土实物，传世辑本（如马国翰《玉函山房辑佚书》所辑）多据类书引文，真伪杂糅，**只能作史料线索，不能当文本依据**。

### 1.3 孔子与《易》："人更三圣"说的史学检讨

旧说依据两条核心材料：

- 《史记·孔子世家》："孔子晚而喜《易》，序《彖》《系》《象》《说卦》《文言》。读《易》，韦编三绝。曰：'假我数年，若是，我于《易》则彬彬矣。'"
- 《汉书·艺文志》："……人更三圣，世历三古。"（颜师古注：三圣谓伏羲、文王、孔子；三古谓上古、中古、下古）

"人更三圣"即：伏羲画八卦 → 文王重为六十四卦并作卦爻辞 → 孔子作《十翼》。这一谱系在宋代开始被系统质疑：

| 质疑者 | 著作 | 主要论点 |
|---|---|---|
| 欧阳修（宋） | 《易童子问》 | 《系辞》《文言》《说卦》文义繁衍、自相矛盾，非孔子所作；"十翼"非一人一时之书 |
| 崔述（清） | 《洙泗考信录》 | 孔子未曾作《易传》，仅"学《易》"而已 |
| 顾颉刚等（民国） | 古史辨派 | 卦爻辞成于西周初叶，非文王一人；《易传》成于战国末至汉初 |
| 李镜池、高亨 | 《周易探源》《周易古经今注》 | 经、传分属两个时代、两种性质，须分开研究 |

**当前主流看法（可作学术共识的表述）**：

- 卦画与卦爻辞是西周前期逐步形成的占筮资料汇编，非一人一时之作；"文王作卦辞、周公作爻辞"属旧说，无直接证据。
- 《易传》七种十篇是战国至汉初儒者解《易》的总集，可能包含孔子后学的材料，但**整体不能视为孔子亲笔**。
- 1973 年马王堆帛书《易传》诸篇（《二三子问》《系辞》《衷》《要》《缪和》《昭力》等）提供了战国晚期至汉初解《易》的实物样本，其文体与今本《系辞》互有异同，进一步支持"《易传》为学派累积文本"的判断。

> 学术态度建议：讲"孔子与《易》"时，区分三个层次——（a）孔子是否读过、重视《易》：证据不强但可信；（b）孔子是否作《易传》：证据不足；（c）孔子及儒家思想是否深刻塑造了《易传》：证据充分。把（c）误当作（b），是通俗读物最常见的错误。

### 1.4 出土文献：改写易学史的四批材料

| 材料 | 出土/入藏 | 内容与价值 |
|---|---|---|
| 马王堆帛书《周易》 | 1973，长沙马王堆三号汉墓（西汉初） | 含帛书《易经》与《系辞》及数篇佚传。**卦序与今本完全不同**：以乾、艮、坎、震、坤、兑、离、巽为上卦顺序，按八宫式重卦排列；卦名多异文（如"乾"作"键"、"坤"作"川"、"艮"作"根"、"坎"作"赣"、"离"作"罗"）。是研究卦序与异文的第一等材料 |
| 阜阳汉简《周易》 | 1977，安徽阜阳双古堆一号汉墓（西汉初） | 残简，存卦画、卦辞与部分爻辞，为现存最早的《周易》抄本之一；卦画用阴阳爻符号，可与今本对校 |
| 上海博物馆藏战国楚竹书《周易》 | 1994 入藏，2003 年《上博藏战国楚竹书（三）》公布 | 战国中期楚简，存 58 简，涉及 34 卦，是目前所见最早的《周易》文本之一；简头有特殊卦画符号，是研究早期卦画形态的关键 |
| 清华简《筮法》 | 2008 入藏清华大学，2013 年《清华大学藏战国竹简（肆）》公布 | 战国竹简，记数字卦筮法，附"八卦方位图"与大量占例，含"爻象""卦位""人身图"等；证明战国筮法远比"大衍之法"一系复杂，另有以数字记爻的独立系统 |

另需提及：

- **数字卦**：北宋重和元年（1118）湖北孝感出土的"中方鼎"等铜器铭文末的数字组合，长期不可解。张政烺《试释周初青铜器铭文中的易卦》（《考古学报》1980年第4期）证明这类"奇字"是用一、五、六、七、八等数字记录的卦爻，即"数字卦"。这解释了《周易》从数字卦到阴阳爻画的演化链条，也印证了"筮，数也"。
- **王家台秦简《归藏》**（见 1.2）。
- 清华简《别卦》等另有卦名与卦序材料，可与帛书本互证。

## 二、象数体系

### 2.1 生成序列：太极 → 两仪 → 四象 → 八卦

《系辞上》："易有太极，是生两仪，两仪生四象，四象生八卦。"这是象数宇宙论的骨架。其数理结构是**二分递推**：

| 层 | 内容 | 数 | 符号表示（以阳=1、阴=0，自下而上书写） |
|---|---|---|---|
| 太极 | 未分之整体 | 1 | — |
| 两仪 | 阳、阴 | 2 | 1 / 0 |
| 四象 | 太阳（老阳）、少阴、少阳、太阴（老阴） | 4 | 11 / 01 / 10 / 00 |
| 八卦 | 乾兑离震巽坎艮坤 | 8 | 111 / 110 / 101 / 100 / 011 / 010 / 001 / 000 |

四象的两种命名系统不要混用：

- **筮法系统**（与大衍之数配套）：老阳（9）、少阴（8）、少阳（7）、老阴（6）。老=变爻，少=不变爻。
- **邵雍系统**（与先天图配套）：太阳、少阳、太阴、少阴，按"阳仪加阳/阴、阴仪加阳/阴"生成。

八卦取象（《说卦》最基本的八项）：

| 卦 | 符号 | 卦画（自下而上） | 基本象 | 性 | 家庭象（《说卦》） | 动物象（《说卦》） |
|---|---|---|---|---|---|---|
| 乾 ☰ | 阳阳阳 | 1 1 1 | 天 | 健 | 父 | 马 |
| 坤 ☷ | 阴阴阴 | 0 0 0 | 地 | 顺 | 母 | 牛 |
| 震 ☳ | 阳阴阴 | 1 0 0 | 雷 | 动 | 长男 | 龙 |
| 巽 ☴ | 阴阳阳 | 0 1 1 | 风（木） | 入 | 长女 | 鸡 |
| 坎 ☵ | 阴阳阴 | 0 1 0 | 水 | 陷 | 中男 | 豕 |
| 离 ☲ | 阳阴阳 | 1 0 1 | 火 | 丽（附） | 中女 | 雉 |
| 艮 ☶ | 阴阴阳 | 0 0 1 | 山 | 止 | 少男 | 狗 |
| 兑 ☱ | 阳阳阴 | 1 1 0 | 泽 | 说（悦） | 少女 | 羊 |

记忆口诀（八卦取象歌，朱熹《周易本义》卷首）："乾三连，坤六断，震仰盂，艮覆碗，离中虚，坎中满，兑上缺，巽下断。"注意"上/下"是就卦画的视觉上下而言，与爻位序号方向相反——这是初学者最常出错处。

### 2.2 先天八卦（伏羲八卦）

**方位**（《说卦》"天地定位，山泽通气，雷风相薄，水火不相射"）：乾南、坤北、离东、坎西、兑东南、震东北、巽西南、艮西北。

**数**：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。

两点必须讲清楚：

1. **先天数不是方位序号**。数字 1–8 沿圆周的顺序是：乾（南）→ 兑（东南）→ 离（东）→ 震（东北）→ 巽（西南）→ 坎（西）→ 艮（西北）→ 坤（北）。即"阳仪四卦顺行、阴仪四卦逆行"的 S 形排布，与方位表的直观方向不同。
2. **先天八卦的"先天"是哲学标签**，不是年代判断。邵雍以"先天"指伏羲之易（体、对待、生成），"后天"指文王之易（用、流行、方位）。这是宋人的体系建构，不可当作史实。

### 2.3 后天八卦（文王八卦）

**方位**：坎北、离南、震东、兑西、乾西北、坤西南、艮东北、巽东南。

**数**（即洛书九宫数）：坎一、坤二、震三、巽四、中五、乾六、兑七、艮八、离九。

《说卦》"帝出乎震"章是后天方位的经典依据："帝出乎震，齐乎巽，相见乎离，致役乎坤，说言乎兑，战乎乾，劳乎坎，成言乎艮。"——把八卦排成一年/一日的循环流行序列，故称"流行"。

| 对比项 | 先天八卦 | 后天八卦 |
|---|---|---|
| 对应人物（旧说） | 伏羲 | 文王 |
| 结构原则 | 对待（阴阳相对） | 流行（时序循环） |
| 乾的位置 | 南 | 西北 |
| 坤的位置 | 北 | 西南 |
| 数序 | 乾1兑2离3震4巽5坎6艮7坤8 | 坎1坤2震3巽4中5乾6兑7艮8离9 |
| 主要用途 | 卦气、象数本体论、梅花易数取数 | 风水（玄空、八宅）、方位占、中医、式盘 |

### 2.4 河图与洛书

**河图**（生成数，五行配属）：

| 方位 | 数（生数 / 成数） | 五行 | 口诀 |
|---|---|---|---|
| 北 | 一 / 六 | 水 | 天一生水，地六成之 |
| 南 | 二 / 七 | 火 | 地二生火，天七成之 |
| 东 | 三 / 八 | 木 | 天三生木，地八成之 |
| 西 | 四 / 九 | 金 | 地四生金，天九成之 |
| 中 | 五 / 十 | 土 | 天五生土，地十成之 |

河图的结构是"一六共宗、二七同道、三八为朋、四九为友、五十同途"，即生数与成数相差 5、同方位配五行。

**洛书**（九宫数）：

| 4 | 9 | 2 |
|---|---|---|
| 3 | 5 | 7 |
| 8 | 1 | 6 |

口诀："戴九履一，左三右七，二四为肩，六八为足，五居中央。"洛书的数理性质：每行、每列、两对角线和皆 15，是标准的三阶幻方。**这一点可独立验算，是河洛之学中少数硬性数学事实。**

**河图与洛书的学理争议**：

- 先秦文献无"河图""洛书"的具体图式，《尚书·顾命》"河图"、《论语·子罕》"河不出图"、《系辞上》"河出图，洛出书，圣人则之"均未言其数。
- 今传图式出自宋代：刘牧《易数钩隐图》以"五行生成图"为洛书、以"九宫图"为河图；朱熹《周易本义》卷首则定为"河图（生成数）""洛书（九宫数）"，此后朱说成为主流。**宋人图式与先秦"河图洛书"名实是否对应，是易学史悬案，不宜断言。**
- 元代以来不断有"河洛即外来数学/幻方"之说，可参考但证据不足。

### 2.5 卦序三系

#### （1）通行本卦序（《序卦传》序）

今本六十四卦的次序（乾坤屯蒙……既济未济）以"非覆即变"为排列原则：相邻两卦或为**综卦**（上下颠倒，如屯/蒙、需/讼），或为**错卦**（六爻全变，如乾/坤、颐/大过、坎/离、中孚/小过）。全序以"有天地然后万物生焉"的宇宙生成论与"物极必反"的历史哲学串讲，见《序卦传》。

**注意**：《序卦传》的解释有明显牵强处（如对"讼"接"需"的说明），且不能解释为何恰是此序。通行本序的成因至今无定论，一说与帛书本同源而各有改编。

#### （2）京房八宫序

以八经卦为"宫"，每宫统八卦，按"本宫—一世—二世—三世—四世—五世—游魂—归魂"的爻变规则生成。这是六爻纳甲（火珠林法）的骨架，详见 `04b` 第一篇。

#### （3）先天六十四卦圆图（伏羲六十四卦方位图）

按"加一倍法"生成：以八卦为上下卦，上卦顺序取乾、兑、离、震、巽、坎、艮、坤（先天八卦序），下卦亦同，得 64 卦后按圆图排布。朱熹《周易本义》卷首所载圆图，自左方乾起逆时针（一说顺时针，视观看方向）依次为：

- **左半（阳仪三十二卦）**：乾、夬、大有、大壮、小畜、需、大畜、泰、履、兑、睽、归妹、中孚、节、损、临、同人、革、离、丰、家人、既济、贲、明夷、无妄、随、噬嗑、震、益、屯、颐、复
- **右半（阴仪三十二卦）**：姤、大过、鼎、恒、巽、井、蛊、升、讼、困、未济、解、涣、坎、蒙、师、遁、咸、旅、小过、渐、蹇、艮、谦、否、萃、晋、豫、观、比、剥、坤

圆图的重要性：**相对位置的两卦互为错卦**（乾↔坤、夬↔剥、大有↔比……），可逐对验算，这是检验圆图排布是否正确的可靠方法。

### 2.6 爻位与筮例条例

六爻自下而上称：初、二、三、四、五、上。阳爻称"九"（初九、九二……上九），阴爻称"六"（初六、六二……上六）。"初""上"标位，"二三四五"标序，故"初九"而非"九初"。

| 条例 | 定义 | 例 |
|---|---|---|
| 当位（得正） | 阳爻居阳位（初、三、五）、阴爻居阴位（二、四、上） | 既济六爻皆当位 |
| 不当位（失正） | 反之 | 未济六爻皆不当位 |
| 得中 | 居二、五爻（下卦、上卦之中） | 九二、六五 |
| 中正 | 既得中又当位：六二、九五 | 需卦九五"中正" |
| 承 | 阴爻在下、阳爻在上，阴承阳 | 坤卦初六"履霜"承阳 |
| 乘 | 阴爻在上、阳爻在下，阴乘阳（乘刚） | 屯卦六二乘初九 |
| 比 | 相邻两爻的亲近关系 | 比卦诸爻 |
| 应 | 初四、二五、三上相应；一阴一阳为"有应"，同性为"无应/敌应" | 泰卦六五应九二 |

**错综复杂**四组关系（务必分清）：

| 名称 | 别名 | 生成方式 | 例（本卦 → 关系卦） |
|---|---|---|---|
| 错卦 | 旁通卦、变卦（汉人旧称） | 六爻阴阳**全部**反转 | 乾 ↔ 坤；泰 ↔ 否 |
| 综卦 | 反卦、覆卦 | 整卦**上下颠倒**（180°旋转） | 屯 ↔ 蒙；需 ↔ 讼 |
| 互卦 | 互体 | 取二三四爻为下互、三四五爻为上互 | 屯（震下坎上）→ 互剥 |
| 变卦 | 之卦 | 某一爻（或数爻）由老变少 | 泰九三变 → 临 |

验算示例（互卦，务必亲手复算）：屯卦 ䷂ 为震下坎上。震 ☳ = 阳阴阴，自下而上记作 1 0 0，占初、二、三爻；坎 ☵ = 阴阳阴，记作 0 1 0，占四、五、上爻。故屯卦六爻自下而上为 **1 0 0 0 1 0**。

- 下互取二、三、四爻 = 0 0 0 = 坤；
- 上互取三、四、五爻 = 0 0 1 = 艮；
- 故互卦为"坤下艮上"= **山地剥**（与表中一致）。

**注意**：互卦取法各家有异（有只取二三四、有取三四五、有以二至四为下互），本篇采"二三四为下互、三四五为上互"的通行法。另需注意，互卦取的是**本卦**的中间四爻；若已有变爻，须说明所取是本卦还是之卦，否则结论无法复核。

最后一个易被忽略的结构：**卦变与卦气**。汉人（孟喜、京房）以十二辟卦（复、临、泰、大壮、夬、乾、姤、遁、否、观、剥、坤）配十二月，以六十卦配三百六十五日，形成"卦气说"。这是象数易学的天文历法化分支，与占筮实践关系较远，但读汉易不可不知。

### 3.1 三道校验

1. **结构**：以"上象 + 下象 + 卦名"记名（水雷屯、山水蒙、火天大有），记不起者回 2.1 符号表现算，勿凭印象。
2. **序卦锚点**：乾/坤、颐/大过、坎/离、中孚/小过四对为错卦；泰/否、随/蛊、渐/归妹、既济/未济四对则综错兼备（互为综卦又互为错卦），其余相邻两卦多为综卦。
3. **大象句式**："（上象 + 下象 + 卦名），君子/先王/后/上/大人以……"，句式不合即记错（例外：乾卦大象作"天行健，君子以自强不息"，不带卦名）；卦画可用 2.1 的二进制与帛书本、京房本互转（公式见 `04b` 第一篇）。

## 四、十翼导读

"十翼"是七种十篇解经文献的总称。"翼"取辅翼经文之意，其名与篇数定于汉代，但各篇成书年代并不一致，学界一般认为自战国中期延续至西汉初。

| 篇目 | 位置/体例 | 核心内容 | 思想价值与阅读提示 |
|---|---|---|---|
| 《彖》上、下 | 附于每卦卦辞之后，共 64 条 | 解释卦名、卦辞，以卦体（上下卦）、卦德（健顺动入等）、卦象、爻位立说，结以"……时大矣哉""……之时义大矣哉" | 是**最早的成体系解经文字**，也是"象数—义理"混合方法的源头；《乾·彖》"大哉乾元，万物资始"确立"元"的宇宙论地位 |
| 《象》上、下 | 分"大象""小象"。大象释卦象（64 条），小象释爻辞（386 条） | 大象取上下卦之象，落到伦理实践（"君子以……"）；小象多就爻位、得中、当位、应位作解 | 大象是《易》伦理化最关键的一步，把自然象转为德性要求（"天行健，君子以自强不息"）；小象则是爻位条例的教科书 |
| 《系辞》上、下 | 通论，不分卦 | 论揲蓍成卦（"大衍之数"章）、卦爻之起源与功能、乾坤之德、言意象关系（"书不尽言，言不尽意""立象以尽意"）、"一阴一阳之谓道""形而上者谓之道" | **哲学价值最高的一篇**，也是中国哲学范畴（道、器、象、意、神、几、变通）的策源地；但其文本层次复杂，有明显的不同来源拼接痕迹 |
| 《文言》 | 仅释乾、坤两卦 | 以"四德"（元亨利贞）释卦辞，以"潜龙勿用"等展开德性论；坤文言有"积善之家必有余庆" | 儒家伦理释《易》的典型文本，文体近于语录与论文之间；一说原本独立成篇，后附于乾坤 |
| 《说卦》 | 通论八卦 | 八卦的方位、取象（天地雷风水火山泽、父母六子、马牛龙鸡豕雉狗羊、首腹足股耳目口手等）、"穷理尽性以至于命" | **象数取象的总库**，占筮取象必据此篇；"帝出乎震"章是后天方位说的经典依据 |
| 《序卦》 | 通论卦序 | 逐对说明六十四卦相次之意，以"有天地然后万物生焉""物不可以终通""穷则变"等串联 | 世界首篇"卦序解释"，但牵强处甚多；其价值在于呈现汉人对"历史—宇宙进程"的整体构想 |
| 《杂卦》 | 通论，韵语 | 以韵文两两对举概括卦义（"乾刚坤柔，比乐师忧"），次序与通行本不同 | 文体特殊，可能保存较早的卦义口诀；末段八卦错杂，疑有错简 |

**读法建议**：先读《彖》《象》以立象数条例，再读《系辞》以通哲学，最后以《说卦》为取象词典、《序卦》《杂卦》为辅助。切勿把十翼当作同质的"孔子语录"——其内部对同一卦的解释已有分歧，正是学派积累的证据。

## 五、大衍筮法

### 5.1 经文依据

《系辞上》："大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰；五岁再闰，故再扐而后挂。……乾之策二百一十有六，坤之策百四十有四，凡三百有六十，当期之日。二篇之策万有一千五百二十，当万物之数也。"

数理自洽性可验算：老阳一爻 36 策，乾六爻皆老阳 = 36×6 = 216 策；老阴一爻 24 策，坤六爻皆老阴 = 24×6 = 144 策；合计 360，当一年之日数。全经 384 爻，阳爻 192、阴爻 192，192×36 + 192×24 = 6912 + 4608 = 11520，即"万物之数"。**这套数字是设计过的，不是偶然。**

### 5.2 操作流程（依朱熹《周易本义》卷首《筮仪》）

准备：蓍草五十策（无蓍草可用竹策、牙签替代，但须五十根且质地一致），置一策于椟中不用，以象太极；实用四十九策。

**一变**
1. **分二以象两**：将四十九策随手分为左右两堆（"信手"而非刻意均分，这一点直接影响概率分布）。
2. **挂一以象三**：从右堆取一策，夹于左手小指与无名指之间。
3. **揲之以四以象四时**：将左堆四策一组分数，余数（1–4；若整除则取 4）夹于左手无名指与中指之间；再以同样方式数右堆，余数夹于中指与食指之间。
4. **归奇于扐**：上述"挂一"加两次"归奇"，合计必为 5 或 9（第一变专有）。将此数移置一旁。余策为 44 或 40。

**二变、三变**
以余策重复 1–4 步。二、三变的"归奇"合计数必为 4 或 8。三变后余策必为 36、32、28、24 之一。

**成爻**
余策除以四：36 → 9（老阳），32 → 8（少阴），28 → 7（少阳），24 → 6（老阴）。九、七为阳爻，八、六为阴爻；九、六为**变爻**（老变少），七、八为不变爻。**三变成一爻，十八变成一卦**：自初爻至上爻依次记录。

**记爻符号**（通行记法）：

| 得数 | 名称 | 通行符号 | 阴阳 | 动静 |
|--:|---|---|---|---|
| 9 | 老阳（重） | ○ | 阳 | 动，变为阴 |
| 8 | 少阴（拆） | ⚋（阴爻符号） | 阴 | 静 |
| 7 | 少阳（单） | ⚊（阳爻符号） | 阳 | 静 |
| 6 | 老阴（交） | × | 阴 | 动，变为阳 |

（符号系统各家小异，有以"／""＼"分记少阳少阴者；记录时以文字"老阳/少阴"为准，最不易混。）

### 5.3 概率分析

设每一步"分二"后，左堆策数对 4 的余数近似等可能（这是理想化假设，实际受"信手"手感影响）。

**第一变**：四十九策分两堆、挂一后共 48 策参与揲数。48 ≡ 0（mod 4），故两堆余数之和为 8，归奇（含挂一）为 9 的概率 1/4、为 5 的概率 3/4。余策 44（3/4）或 40（1/4）。

**第二、三变**：参与揲数的策数 ≡ 3（mod 4）（如 44 挂一后 43），两堆余数之和为 3 或 7，归奇为 4 或 8，**各 1/2**。

由此：

| 结果 | 余策 | 概率推导 | 概率 |
|---|---|---:|---:|
| 老阳 9 | 36 | P(余40后二变)×1/2 = (3/4×1/2)×1/2 = 3/16 | 18.75% |
| 少阴 8 | 32 | 3/16 + 1/4 = 7/16 | 43.75% |
| 少阳 7 | 28 | 1/4 + 1/16 = 5/16 | 31.25% |
| 老阴 6 | 24 | (1/4×1/2)×1/2 = 1/16 | 6.25% |

由此可得两个重要推论：

1. **阳爻概率 = (3/16 + 5/16) = 1/2，阴爻概率 = (7/16 + 1/16) = 1/2**。即单爻阴阳严格等概率——这是好的设计。
2. **变爻概率 = 3/16 + 1/16 = 1/4**，故六个爻全不变的概率为 (3/4)^6 ≈ 17.8%，至少一爻变的概率约 82.2%。这解释了为什么筮例中绝大多数都有变爻。

> **一说的分歧**：有学者主张"挂一"仅施于第一变（二、三变不挂），则二、三变的余策模 4 为 0，归奇概率分布改变，四象概率不再是 3/16、7/16、5/16、1/16。此说与朱熹《筮仪》不合，但提示我们：**"大衍概率"依赖于对操作细节的约定，不是纯粹的数学事实**。引用具体百分比时应说明所依操作版本。

### 5.4 金钱卦（三钱法）

以三枚铜钱（或硬币）投掷六次，自下而上成卦。约定：**有字面（正面）记 2 为阴，无字面（背面）记 3 为阳**（此约定必须全盘统一，若反向则全卦阴阳颠倒）。

| 三枚结果 | 数和 | 名称 | 记法 | 说明 |
|---|---:|---|---|---|
| 三背 | 3+3+3 = 9 | 老阳 | ○（重） | 阳爻，动 |
| 二背一字 | 3+3+2 = 8 | 少阴 | 拆 | 阴爻，静 |
| 一背二字 | 3+2+2 = 7 | 少阳 | 单 | 阳爻，静 |
| 三字 | 2+2+2 = 6 | 老阴 | ×（交） | 阴爻，动 |

概率（假设钱币均匀）：老阳 1/8、少阴 3/8、少阳 3/8、老阴 1/8。变爻概率仍为 1/4，但四象分布与大衍法不同（少阴、少阳各 3/8，而非 7/16、5/16）。**这是两种筮法不可互换的证据之一。**

### 5.5 本卦、之卦、互卦与"贞悔"

| 术语 | 定义 |
|---|---|
| 本卦（正卦） | 依所得六爻直接画成的卦 |
| 之卦（变卦） | 变爻（老阳、老阴）反转后所得之卦；无变爻则无之卦 |
| 互卦 | 本卦二三四爻为下互、三四五爻为上互所得之卦（取法见 2.6） |
| 贞悔 | 《左传》筮例术语，一般以本卦为贞（内、主）、之卦为悔（外、次）；《洪范》"贞悔"另有一说 |

**记录规范**：应写明"本卦某、第几爻动、之卦某、互卦某"。缺一不可复核。例：本卦泰、九三动、之卦临、互卦雷泽归妹（泰 1 1 1 0 0 0，二三四 = 1 1 0 = 兑；三四五 = 1 0 0 = 震。故互卦为"兑下震上"= 雷泽归妹）。读者应自行复算此例。

## 六、断卦规则

### 6.1 朱熹的变爻断法（《易学启蒙·考变占》，义见《周易本义》卷首《筮仪》）

这是现存最系统、最可操作的变占规则，至今仍是学院与术数两界共同援引的标准：

| 情形 | 断法 | 依据 |
|---|---|---|
| 六爻皆不变 | 以**本卦卦辞**断 | 静卦占彖辞 |
| 一爻变 | 以**本卦该变爻的爻辞**断 | 单变直指其事 |
| 二爻变 | 以**本卦两变爻的爻辞**断，**以上爻为主** | 上爻居尊、事之终 |
| 三爻变 | 以**本卦与之卦的卦辞**断，**本卦为贞（主）、之卦为悔（次）** | 贞悔并举 |
| 四爻变 | 以**之卦中两个不变爻的爻辞**断，**以下爻为主** | 反用二爻变之例 |
| 五爻变 | 以**之卦中那个不变爻的爻辞**断 | 反用一爻变之例 |
| 六爻全变 | 乾卦用"用九"、坤卦用"用六"；其余卦以**之卦卦辞**断 | 乾坤二用专为此设 |

朱熹自己的补充很重要：三爻变时，"前十卦主贞，后十卦主悔"（指以本卦为主或以之卦为主的二十种组合），说明规则仍有解释空间。**任何声称"变占只有一条铁律"的说法都不符合朱熹原意。**

### 6.2 义理派与象数派的分歧

| 派别 | 代表人物与著作 | 解《易》方法 | 对占筮的态度 |
|---|---|---|---|
| 象数派（汉） | 孟喜、京房《京氏易传》、郑玄、虞翻（佚说存于李鼎祚《周易集解》） | 卦气、纳甲、爻辰、互体、升降、半象；以历数与卦爻一一对应 | 占验为核心，象数为技术 |
| 义理派（魏—宋） | 王弼《周易注》《周易略例》、程颐《伊川易传》 | "得意忘象""扫象"，以老庄与儒家义理释卦；重爻位、时、中 | 王弼仍存占筮形式，但重心转向哲理；程颐几近纯伦理 |
| 图书派（宋） | 邵雍《皇极经世》、周敦颐《太极图说》、朱熹《周易本义》 | 先天后天、河图洛书、加一倍法；以数学生成解释卦画 | 邵雍重"数"的推演，朱熹兼采象数与义理，并定筮仪 |
| 考据派（清） | 惠栋《周易述》、张惠言、焦循《易学三书》 | 恢复汉易，以训诂、历算、比例说易 | 焦循以"旁通""相错"建构数学化的易学，是象数的理性化尝试 |

**关键判断**：义理与象数不是"正确/错误"的对立，而是**同一文本的两种使用方式**——象数回答"如何取象定吉凶"，义理回答"这套符号对人意味着什么"。王弼"扫象"针对的是汉末象数烦琐化（一卦可生数十种象），而非否定象本身；程颐《伊川易传》不取占筮，却在方法上大量使用爻位条例，可见二者共享同一套形式结构。

### 6.3 断卦的一般次序（经传层）

1. **定卦与变**：确认本卦、动爻、之卦、互卦。
2. **看卦体卦德**：上下卦之象与德（如"水雷屯"= 险中有动，创业者之象）。
3. **看卦辞**：先立大方向。
4. **看变爻爻辞**：按 6.1 规则取用。
5. **看爻位关系**：当位、得中、承乘、应与。
6. **参互卦**：看事情的中段与内部结构。
7. **参之卦**：看趋势与结果。
8. **以义理收束**：不作宿命论判断，落到"此时此位应如何行"。

## 七、自测题（附答案要点）

**1. 简述"三易"说的文献依据与实物证据，并说明为何不能把《连山》当作可用的文本。**
答案要点：《周礼·春官·大卜》"掌三易之法……其经卦皆八，其别皆六十有四"是最可靠的制度性记载；首卦旧说为《连山》首艮、《归藏》首坤、《周易》首乾（郑玄、孔颖达）。实物方面，王家台秦简《归藏》残简是最强证据（1993 年出土，卦名与佚文多合），清华简《筮法》证明战国筮法另成系统。但《连山》无任何出土实物，传世辑本出自类书引文，真伪杂糅，只能作线索。

**2. 用二进制（阳=1、阴=0、自下而上）写出屯、蒙、泰、否四卦，并指出其中哪两对互为综卦、哪两对互为错卦。**
答案要点：屯 = 1 0 0 0 1 0（震下坎上）；蒙 = 0 1 0 0 0 1（坎下艮上）；泰 = 1 1 1 0 0 0（乾下坤上）；否 = 0 0 0 1 1 1（坤下乾上）。屯/蒙互为综卦（上下颠倒），泰/否互为错卦（阴阳全反）兼综卦。校验法：屯上下颠倒得 0 1 0 0 0 1 = 蒙 ✓。

**3. 大衍筮法为何"三变成一爻、十八变成一卦"？请写出四象的概率，并说明变爻概率。**
答案要点：每一变通过"分二、挂一、揲四、归奇"把策数减去 5/9（初变）或 4/8（二三变），三变后余策必为 36/32/28/24，除以四得 9/8/7/6，故三变成一爻；六爻需十八变。概率：老阳 3/16、少阴 7/16、少阳 5/16、老阴 1/16。阴阳各 1/2，变爻（9、6）概率 1/4。若采用"挂一仅初变"的异说，分布改变，须注明版本。

**4. 依朱熹《考变占》，分别说明"一爻变""三爻变""六爻全变"三种情形如何取断。**
答案要点：一爻变——以本卦变爻爻辞断；三爻变——以本卦与之卦卦辞断，本卦为贞为主、之卦为悔为次（朱熹另有"前十卦主贞、后十卦主悔"之说）；六爻全变——乾用"用九"、坤用"用六"，其余卦以之卦卦辞断。另需记住：二爻变以上爻为主，四爻变以之卦二不变爻断且以下爻为主，五爻变以之卦不变爻断。

**5. 河图与洛书在宋代被定形，请说明二者的数字结构，并指出"河图洛书"研究中的主要风险。**
答案要点：河图为五行生成数：北一六水、南二七火、东三八木、西四九金、中五十土；洛书为九宫数，口诀"戴九履一，左三右七，二四为肩，六八为足，五居中央"，每行每列两对角线和皆 15（三阶幻方，可验算）。风险有三：（a）先秦"河图洛书"无图式，今图出自宋人（刘牧与朱熹的河洛名实还相反），不能当作先秦旧物；（b）用河洛附会现代科学（如 DNA、元素周期表）属比附，非学术论证；（c）河洛数与先后天八卦数的配属各家不同，混用会导致整个象数体系自相矛盾。
