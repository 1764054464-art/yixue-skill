# 04b 周易卦象（下）：京房八宫纳甲与梅花易数

> 本篇处理《周易》占筮技术的两大实操系统：**京房八宫纳甲（六爻/火珠林法）** 与 **梅花易数**。
> 两者都以六十四卦为骨架，但取象、取数、断法的逻辑完全不同：前者以**纳甲、五行、六亲**为轴，后者以**先天数、体用**为轴。混用是当代术数书最常见的错误来源。
> 关联篇目：`04a_周易卦象_经传象数与筮法.md`（经传、象数条例、大衍筮法）、`01_基础_阴阳五行干支历法与易学宇宙观.md`（干支五行公理层）。

## 一、京房八宫

### 1.1 京房与《京氏易传》

京房（前 77—前 37），本姓李，字君明，东郡顿丘人，西汉今文易学"京氏学"创始人。《汉书·京房传》载其"好钟律，知音声"，以明灾异得幸，终因政治斗争被杀。其学以**卦气、纳甲、八宫、世应、六亲**为核心，把《周易》改造为一套可运算的占验体系。

著作方面须分辨：

| 书名 | 性质 | 说明 |
|---|---|---|
| 《京氏易传》三卷 | 今存，旧题京房撰 | 八宫、纳甲的原始文献；但经后人辑缀，未必尽为京房手笔 |
| 《易传》诸篇（《汉书·艺文志》著录） | 已佚 | 京氏学原本，多散佚 |
| 后世"火珠林法" | 唐末宋初形成 | 以京房纳甲为骨架，配以六亲、六神、世应、月建日辰，即今之"六爻预测" |
| 《火珠林》一卷 | 旧题麻衣道者撰，实为唐宋间人作 | 六爻法的定型文本 |

**学术提示**：今天俗称的"六爻"并不等于京房原学，而是京房纳甲在唐宋以降与式占、星命、民间占验合流后的产物。京房原书重卦气灾异，今之六爻重世应六亲，两者的理论重心已有位移。

### 1.2 八宫结构：爻变生成规则

八宫以八个经卦（八纯卦）为"宫主"，每宫统八卦。生成规则极简单，可完全机械推演：

1. **本宫卦（八纯卦）**：上下同卦，如乾为天。
2. **一世卦**：本宫卦**初爻**变。
3. **二世卦**：初爻、二爻变（即在一世卦基础上再变二爻）。
4. **三世卦**：初三爻变；**四世卦**：初至四爻变；**五世卦**：初至五爻变。
5. **游魂卦**：在五世卦基础上，**第四爻再变回**（不与本宫同）。
6. **归魂卦**：游魂卦的**内卦三爻全部变回**，与本宫一致。

以乾宫为例验算（阳=1、阴=0、自下而上）：

| 步骤 | 爻画 | 卦 | 说明 |
|---|---|---|---|
| 本宫 | 1 1 1 1 1 1 | 乾为天 | — |
| 一世 | 0 1 1 1 1 1 | 天风姤 | 初变 |
| 二世 | 0 0 1 1 1 1 | 天山遁 | 二变 |
| 三世 | 0 0 0 1 1 1 | 天地否 | 三变 |
| 四世 | 0 0 0 0 1 1 | 风地观 | 四变 |
| 五世 | 0 0 0 0 0 1 | 山地剥 | 五变 |
| 游魂 | 0 0 0 1 0 1 | 火地晋 | 四爻再变回 |
| 归魂 | 1 1 1 1 0 1 | 火天大有 | 内卦变回乾 |

读者可用同一规则在纸上推出其余七宫，再与下表对校。**这是检验是否真正掌握八宫的唯一有效方法**，因为八宫表可以背诵，规则不能。

**校验方法**（三道独立检验，全对才可信任）：

1. **计数校验**：8 宫 × 8 卦 = 64，且 64 个卦名不重不漏。逐卦从 04a 的表勾选，勾满即对。
2. **规则校验**：每宫的一世至五世须符合 1.2 的爻变规则；游魂世四、归魂世三，归魂卦的内卦必与本宫一致（如乾宫归魂"火天大有"内卦为乾 ✓，坎宫归魂"地水师"内卦为坎 ✓）。
3. **卦宫五行校验**：乾兑金、离火、震巽木、坎水、艮坤土。这是六亲推导的前提，错则全盘皆错。

### 1.4 世爻与应爻

世爻代表**求测者自身（或所占之事的主体）**，应爻代表**对方、环境、客体**。定位规则由卦在宫中的位次直接决定：

| 卦类 | 世爻 | 应爻 |
|---|---|---|
| 本宫卦（八纯） | 上爻（六） | 三爻 |
| 一世卦 | 初爻 | 四爻 |
| 二世卦 | 二爻 | 五爻 |
| 三世卦 | 三爻 | 上爻 |
| 四世卦 | 四爻 | 初爻 |
| 五世卦 | 五爻 | 二爻 |
| 游魂卦 | 四爻 | 初爻 |
| 归魂卦 | 三爻 | 上爻 |

规律：应爻 = 世爻 + 3（世应相隔三位：初↔四、二↔五、三↔上、四↔初、五↔二、上↔三）。**记住这一点，世应位置永远不会错**——不必背八行表。

## 二、纳甲与纳支

### 2.1 纳甲原理

"纳甲"意为把十天干纳入八卦。其说以月象为背景（一说本于《说卦》"乾，天也，故称乎父"的乾坤六子说与律历相配）：乾纳甲壬、坤纳乙癸，其余六子各纳一干。十干分配后，八卦与干支形成固定对应，故可由卦画直接推出每一爻的天干地支。

天干分配的总原则：

| 卦 | 纳干 | 说明 |
|---|---|---|
| 乾 ☰ | 内卦甲、外卦壬 | 乾为阳首，纳甲；外卦用壬（阳之终） |
| 坤 ☷ | 内卦乙、外卦癸 | 坤为阴首，纳乙；外卦用癸（阴之终） |
| 震 ☳ | 庚 | 阳卦，内外同干 |
| 巽 ☴ | 辛 | 阴卦，内外同干 |
| 坎 ☵ | 戊 | 阳卦 |
| 离 ☲ | 己 | 阴卦 |
| 艮 ☶ | 丙 | 阳卦 |
| 兑 ☱ | 丁 | 阴卦 |

**为何只有乾、坤内外异干？** 因为十干中甲至癸共十位，六子各占一位（丙丁戊己庚辛），余甲、乙、壬、癸四位正好分给乾坤的内外卦。这一分配是人为约定的结果，其"理据"（月象、律吕）多为汉人后设解释，不必深究，但**表必须记准**。

### 2.2 纳支（纳甲六爻支辰表）

这是全部六爻技术的根表。记诵口诀（相传为《火珠林》所传，各家字句小异）：

> 乾金甲子外壬午，坎水戊寅外戊申；
> 艮土丙辰外丙戌，震木庚子外庚午；
> 巽木辛丑外辛未，离火己卯外己酉；
> 坤土乙未外癸丑，兑金丁巳外丁亥。

口诀只给了**内卦初爻**与**外卦四爻**，其余按"阳卦顺行、阴卦逆行"补足：

- **阳卦（乾、震、坎、艮）**：地支顺行（子→寅→辰→午→申→戌）。
- **阴卦（坤、巽、离、兑）**：地支逆行（未→巳→卯→丑→亥→酉，即每隔一位退行）。

完整表：

| 经卦 | 五行 | 内卦（初、二、三爻） | 外卦（四、五、上爻） |
|---|---|---|---|
| 乾 ☰ | 金 | 甲子、甲寅、甲辰 | 壬午、壬申、壬戌 |
| 坎 ☵ | 水 | 戊寅、戊辰、戊午 | 戊申、戊戌、戊子 |
| 艮 ☶ | 土 | 丙辰、丙午、丙申 | 丙戌、丙子、丙寅 |
| 震 ☳ | 木 | 庚子、庚寅、庚辰 | 庚午、庚申、庚戌 |
| 巽 ☴ | 木 | 辛丑、辛亥、辛酉 | 辛未、辛巳、辛卯 |
| 离 ☲ | 火 | 己卯、己丑、己亥 | 己酉、己未、己巳 |
| 坤 ☷ | 土 | 乙未、乙巳、乙卯 | 癸丑、癸亥、癸酉 |
| 兑 ☱ | 金 | 丁巳、丁卯、丁丑 | 丁亥、丁酉、丁未 |

**逐位验算示例**（合于口诀则对）：

- 乾：内初甲子 ✓（口诀"乾金甲子"），二爻甲寅、三爻甲辰顺行；外四爻壬午 ✓（"外壬午"），五爻壬申、上爻壬戌顺行。
- 坎：内初戊寅 ✓（"坎水戊寅"），外四戊申 ✓（"外戊申"）——注意内外初爻相隔六位（寅→申为冲），这正是坎为"重险"之象的数理体现。
- 坤：内初乙未 ✓（"坤土乙未"），内二乙巳、内三乙卯逆行；外四癸丑 ✓（"外癸丑"），外五癸亥、上六癸酉逆行。
- 兑：内初丁巳 ✓（"兑金丁巳"），外四丁亥 ✓（"外丁亥"）。

**装卦操作**：先定上下卦 → 查上表得上卦三爻、下卦三爻的地支与干 → 按初至上的顺序排列，即得六爻干支。注意：**外卦的地支按外卦自身的三位排（四、五、上），不是内卦的延续**，这是初学者最易错处。

### 2.3 六亲

六亲由"卦宫五行"与"爻支五行"的生克关系推出，以宫为"我"：

| 关系 | 六亲 | 含义（占断取象） |
|---|---|---|
| 同我（比和） | 兄弟 | 同辈、竞争者、合伙人、耗财之神 |
| 我生 | 子孙 | 子女、福神、医药、僧道、解忧之神、生财之源 |
| 生我 | 父母 | 父母长辈、文书、房屋、车船、学业、庇护 |
| 我克 | 妻财 | 财物、妻妾、佣人、所支配之物 |
| 克我 | 官鬼 | 官职、丈夫、疾病、盗贼、诉讼、约束 |

以乾宫（金）为例：金=兄弟、水=子孙、土=父母、木=妻财、火=官鬼。
以坎宫（水）为例：水=兄弟、木=子孙、土=官鬼、金=父母、火=妻财。
以离宫（火）为例：火=兄弟、土=子孙、木=父母、金=妻财、水=官鬼。
以坤宫（土）为例：土=兄弟、金=子孙、火=父母、水=妻财、木=官鬼。

**快速推法**：只需记住宫五行，然后按"同、生、生我、我克、克我"五行一转即得。切勿死背六亲表——六十四卦共 384 爻，背不完，只能推。

### 2.4 六神

六神（六兽）按**日干**起，自初爻至上爻依"青龙→朱雀→勾陈→螣蛇→白虎→玄武"顺序轮转：

| 日干 | 初爻 | 二爻 | 三爻 | 四爻 | 五爻 | 上爻 |
|---|---|---|---|---|---|---|
| 甲、乙 | 青龙 | 朱雀 | 勾陈 | 螣蛇 | 白虎 | 玄武 |
| 丙、丁 | 朱雀 | 勾陈 | 螣蛇 | 白虎 | 玄武 | 青龙 |
| 戊 | 勾陈 | 螣蛇 | 白虎 | 玄武 | 青龙 | 朱雀 |
| 己 | 螣蛇 | 白虎 | 玄武 | 青龙 | 朱雀 | 勾陈 |
| 庚、辛 | 白虎 | 玄武 | 青龙 | 朱雀 | 勾陈 | 螣蛇 |
| 壬、癸 | 玄武 | 青龙 | 朱雀 | 勾陈 | 螣蛇 | 白虎 |

口诀："甲乙起青龙，丙丁起朱雀，戊日起勾陈，己日起螣蛇，庚辛起白虎，壬癸起玄武。"（即从该日干对应之神起，依次顺排。）

六神取象：

| 六神 | 五行 | 主事 | 断法提示 |
|---|---|---|---|
| 青龙 | 木 | 喜庆、酒色、财喜、高贵 | 临用神多吉，主喜事、婚姻、升迁 |
| 朱雀 | 火 | 口舌、文书、信息、诉讼 | 临用神主口舌是非，亦主文书信息 |
| 勾陈 | 土 | 田土、房产、牢狱、迟滞 | 主田土房产，亦主牵连拖延 |
| 螣蛇 | 火（一说土） | 虚惊、怪异、缠绕、梦寐 | 主惊恐怪异、心神不宁 |
| 白虎 | 金 | 凶伤、疾病、丧服、道路 | 主伤病丧，亦主道路、威权 |
| 玄武 | 水 | 盗贼、暗昧、私情、欺骗 | 主失盗、暧昧、暗昧不明 |

> **一说的分歧**：螣蛇的五行归属，有作火、有作土（因"螣蛇"本为神兽而非五行实体）。此处只影响极细的旺衰判断，主流六爻书多不以为意。

### 2.5 装卦完整示例（不含断语，断语见第五章卦例二）

以**水雷屯**为例，坎宫二世卦，宫五行属水：

| 爻位 | 卦画 | 纳甲（干·支·五行） | 六亲 | 世应 |
|---|---|---|---|---|
| 上六 | ⚋ | 戊子（水） | 兄弟 | — |
| 九五 | ⚊ | 戊戌（土） | 官鬼 | 应 |
| 六四 | ⚋ | 戊申（金） | 父母 | — |
| 六三 | ⚋ | 庚辰（土） | 官鬼 | — |
| 六二 | ⚋ | 庚寅（木） | 子孙 | 世 |
| 初九 | ⚊ | 庚子（水） | 兄弟 | — |

验算链：屯 = 震下坎上 → 下卦震：庚子、庚寅、庚辰（内三爻）；上卦坎：戊申、戊戌、戊子（外三爻）。坎宫属水，故子水兄弟、寅木子孙、辰土官鬼、申金父母、戌土官鬼。二世卦世二应五 ✓。

### 2.6 伏神与飞神

若卦中**无用神**（占财而卦无妻财，占官而卦无官鬼等），则须从**本宫首卦（八纯卦）**中找出该六亲之爻，称为"伏神"；其所伏居的卦中之爻，称为"飞神"。

规则：伏神必伏于本卦**同一爻位**之下。如占财得屯卦，屯无妻财，取坎宫首卦"坎为水"之妻财爻——坎卦六三为戊午火（水克火为妻财）——戊午火即伏神，伏于屯卦六三庚辰土（飞神）之下。

伏神能否"出伏"，看四组关系：

| 关系 | 判断 | 吉凶 |
|---|---|---|
| 飞神生伏神 | 得长生，伏神易出 | 吉 |
| 伏神生飞神 | 泄气，伏神难出且耗 | 平中偏凶 |
| 飞神克伏神 | 受制，伏神难出 | 凶 |
| 伏神克飞神 | 伏神有力，可出 | 吉 |
| 伏神临日辰/月建 | 伏而"出现"，可用 | 吉 |
| 日辰冲飞神 | "冲飞露伏"，伏神易出 | 吉 |
| 伏神旬空/月破 | 出亦无力 | 凶 |

## 三、断卦要素

六爻断卦不是"看一个爻定吉凶"，而是**多层信息的加权综合**。以下八项是必须逐项过一遍的检查表，漏掉任何一项都可能导致误判。

### 3.1 月建与日辰

| 项目 | 定义 | 作用 |
|---|---|---|
| 月建（月令、提纲） | 占卦之月的月支（如正月建寅） | 定六爻的**旺衰等级**，管一月之事 |
| 日辰（日建、主宰） | 占卦日的日干支 | 对六爻有**生、克、冲、合、拱、扶**之权，管当日之事 |

传统说法："月建为提纲，日辰为主宰。""日辰能生克冲合诸爻，诸爻不能生克日辰。"可见日辰权重高于月建。判断顺序通常为：先看月建定旺衰，再看日辰定生克。

**旺相休囚死**（以月建为准的五级状态）：

| 季节（月建） | 旺 | 相 | 休 | 囚 | 死 |
|---|---|---|---|---|---|
| 春（寅卯） | 木 | 火 | 水 | 金 | 土 |
| 夏（巳午） | 火 | 土 | 木 | 水 | 金 |
| 秋（申酉） | 金 | 水 | 土 | 火 | 木 |
| 冬（亥子） | 水 | 木 | 金 | 土 | 火 |
| 四季月（辰戌丑未） | 土 | 金 | 火 | 木 | 水 |

记忆法："当令者旺，我生者相，生我者休，克我者囚，我克者死。"

两种由日月派生的状态：

- **月破**：爻支与月建相冲（如月建为子，卦中见午爻）。月破之爻当月无力，出月方可用。
- **日破 / 暗动**：静爻与日辰相冲。若该爻旺相，为"暗动"（暗中发动，有力）；若休囚，为"日破"（冲散无用）。**同是日冲，旺衰不同而吉凶相反**，这是六爻最见功力的判断点之一。

### 3.2 旬空

天干十、地支十二，日干支循环中每旬必有两个地支轮空，称"旬空（空亡）"。

| 旬 | 空亡 |
|---|---|
| 甲子旬（甲子—癸酉） | 戌、亥 |
| 甲戌旬（甲戌—癸未） | 申、酉 |
| 甲申旬（甲申—癸巳） | 午、未 |
| 甲午旬（甲午—癸卯） | 辰、巳 |
| 甲辰旬（甲辰—癸丑） | 寅、卯 |
| 甲寅旬（甲寅—癸亥） | 子、丑 |

推法：由日干支逆推至本旬甲日，数出所缺两支。如戊午日，属甲寅旬（甲寅、乙卯、丙辰、丁巳、戊午…），故空子、丑。

旬空的断法分两种：

- **真空**：爻休囚无气又空 → 到底无用，作"无"论。
- **假空**：爻旺相有气而空，或动爻空、伏神空 → 出旬、填实（值该支之日）、冲空之时即可用。

**关键**：空不等于无。判断"真空/假空"须结合月建日辰，这是六爻书反复强调而初学者最易忽略的一点。

### 3.3 动爻与变爻

动爻（老阳、老阴）是卦中"变化的信息源"，变爻是变化之后的状态。主要关系：

| 关系 | 定义 | 吉凶倾向 |
|---|---|---|
| 回头生 | 变爻生动爻 | 吉，动而有助 |
| 回头克 | 变爻克动爻 | 凶，动而受伤 |
| 动化进神 | 变爻为动爻的"顺进"支 | 吉，事渐进展 |
| 动化退神 | 变爻为动爻的"顺退"支 | 凶，事渐消退 |
| 动化空 | 变爻旬空 | 事虚，难成 |
| 动化墓 | 变爻为动爻之墓支 | 事入困局，须待冲墓 |
| 动化绝 | 变爻为动爻之绝支 | 事绝，少望 |

**进神、退神表**（同五行顺行为进、逆行为退）：

| 五行 | 进神 | 退神 |
|---|---|---|
| 水 | 亥 → 子 | 子 → 亥 |
| 木 | 寅 → 卯 | 卯 → 寅 |
| 火 | 巳 → 午 | 午 → 巳 |
| 金 | 申 → 酉 | 酉 → 申 |
| 土 | 丑→辰、辰→未、未→戌、戌→丑 | 辰→丑、未→辰、戌→未、丑→戌 |

另有"化绝"的地支对应（依十二长生）：如水绝于巳、木绝于申、火绝于亥、金绝于寅、土绝于亥（一说绝于巳，随水土同行）。**十二长生系统的"土"一向有分歧，遇土爻化绝宜标"一说"**。

### 3.4 反吟与伏吟

| 名称 | 定义 | 象义 |
|---|---|---|
| 反吟 | 变卦六爻纳支与本卦**同位相冲** | 反复无常、事与愿违、去而复返 |
| 伏吟 | 变卦六爻纳支与本卦**同位相同** | 呻吟不安、停滞不动、事无进展 |

以八纯卦为例可自行推导验证（用 2.2 表逐位核对）：

- **乾变震**：乾之纳支为子、寅、辰、午、申、戌，震之纳支亦为子、寅、辰、午、申、戌，六位全同 → **伏吟**。
- **坤变巽**：坤为未、巳、卯、丑、亥、酉；巽为丑、亥、酉、未、巳、卯。逐位相较，未↔丑、巳↔亥、卯↔酉、丑↔未、亥↔巳、酉↔卯，六位全冲 → **反吟**。

> **一说的分歧**：反吟、伏吟的卦例，各家所举并不一致（有以卦象相错为反吟者，有以纳支相冲为反吟者），《增删卜易》与《卜筮正宗》所述亦有出入。本编取"纳支同位相冲/相同"说，因其可机械验算、结论唯一。学人应先固定一家之例，否则无法复核。

### 3.5 三合局与三刑

**三合局**（四组）：

| 三合局 | 三支 | 所合五行 |
|---|---|---|
| 申子辰 | 申、子、辰 | 合水局 |
| 亥卯未 | 亥、卯、未 | 合木局 |
| 寅午戌 | 寅、午、戌 | 合火局 |
| 巳酉丑 | 巳、酉、丑 | 合金局 |

成局条件：卦中三爻齐全（至少两爻动，另一爻由日辰或月建补足），且三支须"会聚"于同一事。三合成局则力量大增：成用神局则吉，成忌神局则凶。

**三刑**（备参）：寅巳申三刑、丑戌未三刑、子卯相刑、辰午酉亥自刑。刑主伤病、官非、牵连，但六爻中远不如冲合重要，且各家取用不一，宜作辅助信息。

**冲、合、刑、害的层级**：六爻断事以**生克冲合**为主干，刑害为辅。不要把刑害提到与冲合同等的地位，这是术数书常见的夸大。

### 3.6 六冲卦与六合卦

由纳支结构可机械判定，**不必背**：

- **六冲卦（10 个）**：八纯卦（乾、坤、坎、离、震、巽、艮、兑）+ **天雷无妄** + **雷天大壮**。
  验算：无妄为乾上震下，纳支初至四为子、寅、辰、午，子午冲、寅申冲、辰戌冲，六位皆冲 ✓。
- **六合卦（8 个）**：**地天泰、天地否、雷地豫、地雷复、水泽节、火山旅、山火贲、泽水困**。
  验算：泰为坤上乾下，纳支为子、寅、辰、丑、亥、酉；初四子丑合、二五寅亥合、三上辰酉合 ✓。

断法：六冲主**散、快、不成、变动**；六合主**成、慢、和合、纠缠**。占病见六冲多主病散（吉），占婚见六冲多主不成（凶），占出行见六冲主速发。**同一结构因所占之事不同而吉凶相反**，这是六爻"以事取义"的核心，不存在固定吉凶。

### 3.7 用神、元神、忌神、仇神

**用神**是所问之事的"代表爻"，取错用神则全盘皆错。取法：

| 占问之事 | 用神 |
|---|---|
| 求财、买卖、妻妾、佣人 | 妻财 |
| 功名、官职、丈夫、疾病、盗贼、官非 | 官鬼 |
| 父母、长辈、文书、房屋、车船、学业 | 父母 |
| 子女、晚辈、医药、僧道、解忧、生财之源 | 子孙 |
| 同辈、兄弟、合伙人、竞争者 | 兄弟 |
| 自己（总体处境） | 世爻 |

用神在卦中可能出现两次以上（"用神两现"），取法：取动者、取临日月者、取不空不破者、取与世爻有关者；若皆静皆旺，多取应爻或近世者。**用神两现是断卦分歧的高发区，应力求说明取舍理由。**

四种神煞关系（以用神为中心）：

| 名称 | 定义 | 作用 |
|---|---|---|
| 元神（原神） | **生用神**之爻 | 有助用神，元神旺则事成 |
| 忌神 | **克用神**之爻 | 有害用神，忌神旺则事败 |
| 仇神 | **克元神、生忌神**之爻 | 间接为害，断卦中常被忽略 |
| 进神/退神 | 见 3.3 | 主事之进退 |

判吉凶的基本公式：**用神旺相、得元神生扶、不受忌神克害 → 吉；用神休囚、被忌神克、元神无力 → 凶。** 若用神伏藏、旬空、月破、入墓，则须看能否"出伏、出空、填实、冲墓"。

### 3.8 应期判断

应期（何时应验）是六爻中最难、也最容易被滥断的部分。基本规则：

| 用神状态 | 应期取法 |
|---|---|
| 旺相安静 | 待**冲**之日/月（冲以动之） |
| 休囚无力 | 待**旺相**之月日（值月、值日） |
| 旬空 | 待**出空**、**填实**（值空支之日）、**冲空** |
| 伏藏 | 待**值日**（伏神值日）、**冲飞**（冲开飞神）、飞神受制 |
| 发动 | 事急，**即时应验**，或取动爻值日 |
| 被合 | 待**冲开**合局 |
| 被冲 | 待**合**（合住冲神） |
| 入墓 | 待**冲墓** |
| 化进神 | 近期可成；**化退、化空、化绝**则无期或期远 |
| 六合卦 | 事缓，应期迟 |
| 六冲卦 | 事速，应期近 |

**方法论警告**：应期规则的可选空间极大（月、日、值、冲、合、填实，任取其一都能"说通"），因此它是六爻中最不可证伪的环节。严肃的实践应**预先写下应期假设再核对结果**，否则必然陷入事后附会。

### 3.9 步骤化断卦流程（八步）

1. **定卦与卦宫**：由六爻画定本卦，查八宫表定宫与世应。
2. **装卦**：纳甲、纳支、六亲、六神、伏神，逐爻填表。
3. **记时**：写明占卦的年月日时干支，标出月建、日辰、旬空。
4. **取用神**：依所占之事取六亲；用神不上卦则寻伏神。
5. **判旺衰**：以月建定旺相休囚死，以日辰定生克冲合；标出月破、日破、暗动、旬空。
6. **察动变**：动爻的回头生克、化进退、化空墓绝；有无反吟伏吟、三合局。
7. **定吉凶**：综合用神、元神、忌神、世应的生克关系，给出主结论（成/不成、吉/凶、有/无）。
8. **定应期**：按 3.8 给出时间假设，并注明不确定度。

## 四、梅花易数

### 4.1 邵雍与《梅花易数》其书

邵雍（1011—1077），字尧夫，谥康节，北宋五子之一，著有《皇极经世》《伊川击壤集》。其学以"元会运世"推历史，以"加一倍法"说卦画生成，是宋代象数—图书之学的代表。

**辨伪要点**（不可不辨）：

| 项目 | 事实 |
|---|---|
| 《皇极经世》 | 邵雍真作，体系宏大，讲历史推演，非占卜手册 |
| 《梅花易数》 | **题邵雍撰，实为后世托名编纂**。今传本文字浅近，多用明人术语（如"体用""三要十应"的说法定型较晚），学界多定为明清间术士汇编 |
| 因此 | 讲"邵雍的梅花易数"时应说"旧题邵雍撰"，不可当作北宋原书引用 |

尽管如此，《梅花易数》在术数史上影响极大，其"以数起卦、以体用断卦"的方法简洁可操作，是宋明以降民间占卜的主流之一。

### 4.2 起卦法

梅花易数的核心是**把"数"转成卦**，故凡可数、可感之物皆可起卦。常用五种：

**（1）时间起卦（年月日时起卦）**

- 上卦 =（年支数 + 农历月数 + 农历日数）÷ 8 的余数（余 0 作 8）
- 下卦 =（年支数 + 农历月数 + 农历日数 + 时支数）÷ 8 的余数（余 0 作 8）
- 动爻 =（年支数 + 农历月数 + 农历日数 + 时支数）÷ 6 的余数（余 0 作 6）

| 取数项 | 取法 |
|---|---|
| 年支数 | 子 1、丑 2、寅 3、卯 4、辰 5、巳 6、午 7、未 8、申 9、酉 10、戌 11、亥 12 |
| 月数 | 农历月份（正月 1 … 十二月 12） |
| 日数 | 农历日（初一 1 … 三十 30） |
| 时支数 | 子 1、丑 2 … 亥 12（**不是**现代小时数） |

**（2）数字起卦**

- 两数：第一数 ÷ 8 取余为上卦，第二数 ÷ 8 取余为下卦，两数之和 ÷ 6 取余为动爻。
- 一数：可拆为两数（如 123 拆 1 与 23），或"一数加时数"再分。

**（3）字数起卦**

- 二字：上字笔画 ÷ 8 为上卦，下字笔画 ÷ 8 为下卦，总笔画 ÷ 6 为动爻。
- 三字以上：字数分前后两半，前半总和 ÷ 8 为上卦，后半总和 ÷ 8 为下卦，总字数 ÷ 6 为动爻。
- 一字：以笔画分阴阳，或以"一字加时数"处理（各家不一，须注明所依）。

**（4）声音起卦**：以听到的声音数（次数、或所言之字数）起卦，法同上。

**（5）方位起卦**：以人或物所在方位取**后天八卦**方位（坎北、离南、震东、兑西、乾西北、坤西南、艮东北、巽东南）起卦，再加时数取动爻。

**（6）外应（三要十应）**：起卦时同步观察周围异常现象（声音、颜色、人物、方位），作为断卦的辅助印证。这是梅花易数最具特色也最不可检验的部分，见 6.2 的批评。

### 4.3 体用、互卦、变卦

| 概念 | 定义 | 意义 |
|---|---|---|
| 体卦 | 动爻**不在**的那一卦（上或下） | 代表求测者自身、主体 |
| 用卦 | 动爻**所在**的那一卦 | 代表所占之事、对方、客体 |
| 互卦 | 本卦二三四爻为下互、三四五爻为上互 | 事情的中段过程、内在结构 |
| 变卦 | 动爻变后所得之卦 | 事情的最终结果 |

**判断"体"的关键**：动爻所在之卦为"用"，另一卦为"体"。若动爻在上卦，则上卦为用、下卦为体；动爻在下卦则反之。**这一步做错，全盘皆错。**

### 4.4 体用生克断法

以体卦五行为"我"，用卦五行为"事"，按生克定吉凶：

| 关系 | 象义 | 吉凶 |
|---|---|---|
| 用生体 | 外来资助、有进益 | 吉，事易成且有得 |
| 体用比和 | 同气相求、彼此协力 | 吉，顺遂 |
| 体克用 | 我制彼，须费力 | 小吉，事可成而劳 |
| 体生用 | 我耗于彼，泄气 | 不利，耗损、失脱 |
| 用克体 | 彼来伤我 | 凶，阻力大 |

再叠加三层修正：

1. **四时旺衰**：春木旺、夏火旺、秋金旺、冬水旺、四季月（辰戌丑未）土旺。体卦旺则吉上加吉，体卦衰则吉亦减力。
2. **互卦**：生体者吉、克体者凶，主中段过程。
3. **变卦**：生体者终吉、克体者终凶，主结果。**变卦为最终定论**，古法"变卦为事之终"。

## 五、卦例三则

> 说明：例一、例二为教学拟例（为展示完整流程而设，非古籍原例），例三为《梅花易数》原书所载名例。凡拟例均标明，不与文献记载混淆。

### 5.1 卦例一：大衍筮法（一爻变）

**设问**：某事久拖未决，问其进退。
**起卦**：依 04a 第五章大衍法，十八变后得下列余策（每变起于四十九策）：

| 爻位 | 一变后 | 二变后 | 三变后 | ÷4 | 爻性 |
|---|---:|---:|---:|---:|---|
| 上六 | 44 | 36 | 32 | 8 | 少阴（静） |
| 六五 | 40 | 36 | 32 | 8 | 少阴（静） |
| 六四 | 44 | 40 | 32 | 8 | 少阴（静） |
| 九三 | 44 | 40 | 36 | 9 | **老阳（动）** |
| 九二 | 40 | 32 | 28 | 7 | 少阳（静） |
| 初九 | 44 | 36 | 28 | 7 | 少阳（静） |

**成卦**：自下而上 1 1 1 0 0 0 = 乾下坤上 = **地天泰** ䷊。九三为老阳，变阴，得之卦 1 1 0 0 0 0 = 兑下坤上 = **地泽临** ䷒。

**互卦验算**：泰 1 1 1 0 0 0。下互（二三四）= 1 1 0 = 兑；上互（三四五）= 1 0 0 = 震。故互卦为"兑下震上"= **雷泽归妹** ䷵。

**取断**：一爻变，依朱熹《考变占》以本卦变爻爻辞断，即**泰九三**："无平不陂，无往不复，艰贞无咎。勿恤其孚，于食有福。"

**断语**：

- 泰为天地交、上下通之卦，本是大通之象；然九三居下卦之末、将入上卦，正是"泰极将否"的转折位，故爻辞以"无平不陂，无往不复"示警。
- "艰贞无咎"：事在艰难处，守正不动摇则无咎——对应所问"久拖未决"，结论是**不可急进，守正待时**。
- "勿恤其孚，于食有福"：不必忧疑对方的诚意，终有实得。
- 之卦为临，"临"有临下、渐进、二月之象，趋势向好而非骤变。
- 互卦归妹，主中段有"配合不当、名分未正"之扰，正合"久拖"之象。
- 综合：短期仍有反复，宜守正待时，不宜强求速决；得一爻变，事应较近。

### 5.2 卦例二：六爻纳甲（完整装卦）

**占问**：求财（拟例）。
**时间**：甲子年 丙寅月 戊午日（旬空：子、丑）。
**卦**：水雷屯 ䷂，坎宫二世卦，宫五行属水，世二应五。

**装卦表**：

| 爻位 | 六神 | 伏神 | 本卦（纳甲·五行·六亲） | 世应 | 备注 |
|---|---|---|---|---|---|
| 上六 | 朱雀 | — | 戊子（水）兄弟 | — | 旬空 |

**装卦验算**：
- 屯 = 震下坎上。下卦震：庚子、庚寅、庚辰；上卦坎：戊申、戊戌、戊子 ✓。

- 屯无妻财，取本宫首卦"坎为水"六三戊午火（水克火为妻财）为**伏神**，伏于六三庚辰土（飞神）之下 ✓。
- 六三阴爻动变阳：屯 1 0 0 0 1 0 → 1 0 1 0 1 0 = 离下坎上 = **水火既济**；变爻九三纳甲为己亥（离内卦己卯、己丑、己亥）✓。

**断卦八步复盘**：

1. **定卦与宫**：水雷屯，坎宫二世，世二应五。
2. **装卦**：见表。
3. **记时**：月建丙寅（木旺），日辰戊午（火），旬空子、丑。
4. **取用神**：占财以**妻财**为用神。妻财午火不上卦，伏于六三官鬼庚辰土之下。
5. **判旺衰**：
   - 伏神午火**临日辰**（戊午日），虽伏而有气，属"伏神出现"。
   - 飞神辰土受月建寅木克制（木克土），压制之力不强。
   - 但伏神午火生飞神辰土（火生土），为"伏去生飞"，泄气于官鬼——**财气被官鬼（耗财之神）分泄**。
   - 初九、上六两兄弟子水皆旬空，劫财之力暂弱；然出空后仍有夺财之虞。
6. **察动变**：六三官鬼辰土发动，化出兄弟己亥水。官鬼动本已耗财，又化兄弟（劫财之神），为"化出忌神"；且亥水与本爻辰土，动爻克变爻，动而耗力。
7. **定吉凶**：用神有气而不旺（伏、泄气），忌神（兄弟）空而未实，飞神受制。综合判为：**财可得而薄，且须费口舌、防分夺**。非大得之象，但亦非全无。
8. **定应期**：伏神午火为用，取**午日**（伏神值日）或**戌日**（冲开飞神辰土，"冲飞露伏"）；亦可取午月。得财之后防兄弟出空（子、丑出空）之日有人分夺。

**断语**（可直接交付求测者的表述）：

> 财爻不上卦而伏于官鬼之下，说明此财须经他人之手或依附某事而得，不是现成可取的。日辰午火扶起财爻，故财源是有的；但财爻之气泄于官鬼，得之必耗去一部分（如打点、手续费、中间人）。卦中兄弟两重而旬空，眼下无人争夺，但旬空一过便要防同辈分利。六三发动化出兄弟，正是"事情一动，就有人来分"的象。建议：可求，但不宜把预期定高；成事宜选午日、戌日；得手后立即落袋，勿再张扬。应期以近日之午、戌为先。

### 5.3 卦例三：梅花易数"观梅占"（《梅花易数》卷一原例）

**原委**（据原书节述）：辰年十二月十七日申时，邵康节（旧题）观梅，见二雀争枝坠地。曰："不动不占，不因事不占。今二雀争枝坠地，怪也。"因占之。

**起卦计算**：

| 步骤 | 计算 | 结果 |
|---|---|---|
| 年支数 | 辰 = 5 | 5 |
| 月数 | 十二月 = 12 | 12 |
| 日数 | 十七日 = 17 | 17 |
| 上卦 | (5 + 12 + 17) = 34；34 ÷ 8 = 4 余 **2** | 2 = **兑** |
| 时支数 | 申 = 9 | 9 |
| 下卦 | (34 + 9) = 43；43 ÷ 8 = 5 余 **3** | 3 = **离** |
| 动爻 | 43 ÷ 6 = 7 余 **1** | **初爻动** |

**成卦**：上兑下离 = **泽火革** ䷰。初爻动，变**泽山咸** ䷞。
**互卦**：革 1 0 1 1 1 0。下互（二三四）= 0 1 1 = 巽；上互（三四五）= 1 1 1 = 乾。故互卦为"巽下乾上"= **天风姤** ䷫（原书作"互见乾巽"，即此）。
**体用**：动爻在初爻（下卦），故**下卦离为用，上卦兑为体**。

**原书断语之要**："明晚当有女子折花，园丁不知而逐之，女子失惊坠地，遂伤其股。"

**推理链（原书逻辑）**：

1. 体卦兑，兑为**少女**；用卦离为火，**火克金**（克体）→ 少女受伤之象。
2. 互卦上乾下巽：巽为**股**（《说卦》"巽为股"），乾金、兑金克巽木 → 股部受伤。
3. 变卦为咸，下卦变艮，艮为土，**土生金**（生体）→ 虽伤而不至凶危。
4. 时间"明晚"：离为明、为火，得夜之象；初爻动主近事。

**方法论意义**：此例是"体用 + 互变 + 取象"三位一体的范式：**用克体定凶，互卦定受伤部位，变卦定结局轻重**。它同时暴露了梅花易数的软肋——从同一组卦象可以抽取出少女、股、明晚、园丁等大量细节，每一步取象虽合《说卦》，却无法排除"事后拟合"。见 6.2。

## 六、批评与局限

### 6.1 象数与义理之争的实质

04a 已述两派源流。若从"占验有效性"的角度看，争论的实质是：

- **象数派**主张卦象与人事之间有**固定的对应规则**（纳甲、世应、六亲），因而占断可以标准化、可重复。代价是规则极度繁复，且不同规则互相冲突（用神两现、反吟取法、应期取法皆无统一解）。
- **义理派**主张《易》的价值在"时中""忧患""变通"的智慧，占卜只是"神道设教"的外壳。程颐《伊川易传》几不言占，即此立场。

二者其实共享同一形式结构（爻位、卦德），分歧在**是否承认符号与事件之间存在因果通道**。

### 6.2 或然率与确认偏误

这是对占筮最有力的现代批评，须正面面对：

1. **输出是高熵的**。大衍法四象概率 3/16、7/16、5/16、1/16，六爻组合 4⁶ = 4096 种可能的"四象串"，对应极多卦象组合。解释空间巨大，任何结果都能被解释。
2. **解释的自由度极高**。六爻断卦至少有八个可调参数（用神选取、旺衰、旬空真假、动变、冲合、应期），梅花易数则有体用、互变、外应多重取象。**自由度越高，可证伪性越低**。
3. **确认偏误（confirmation bias）**：人倾向于记住应验的案例、忘记不应验的案例。术数实践天然缺乏"预登记"与"对照记录"。
4. **事后归因（hindsight bias）**："早知如此"的解释在事后总能成立，但在事前无法区分。
5. **巴纳姆效应**：断语中"宜守不宜进""防口舌""须待时"一类表述对多数情境都成立，却会被求测者体验为"很准"。

**检验建议**：若要真检验，须做到（a）事前书面写下具体预测（含时间、事件类型、可观测标准）；（b）系统记录全部案例而非只记应验者；（c）与随机对照（如随机抽卦）比较命中率。至今没有学界认可的、通过此类检验的公开研究。

### 6.3 《易》的哲学价值与占卜功能的分离

必须区分两个命题：

- **命题 A**：《周易》经传是中国哲学的重要源头，其"一阴一阳之谓道""穷则变，变则通""时中""忧患意识"具有独立的思想价值。
- **命题 B**：依《周易》筮法可以预测具体事件。

A 为真，**不能推出** B 为真。承认 A 而不承认 B，是完全自洽的立场（朱熹本人即重筮法，但其哲学价值并不依赖占验；程颐则几乎弃占）。反之，用 A 的崇高为 B 背书，是常见的论证跳跃。

### 6.4 当代学术研究路径

| 路径 | 代表方向 | 说明 |
|---|---|---|
| 出土文献与文本考据 | 马王堆帛书、上博简、清华简《筮法》、数字卦 | 重建早期易学的真实形态，是当前最活跃的领域 |
| 易学史与思想史 | 朱伯崑《易学哲学史》、廖名春、林忠军 | 把易学作为思想史对象，而非占卜手册 |
| 数术史 | 李零《中国方术考》《中国方术续考》 | 把筮法放回方术整体脉络中考察，避免"易学中心论" |
| 科学史与数学史 | 卦爻与二进制、莱布尼茨与白晋的通信 | 须严格区分"结构同构"与"历史影响"，二者常被混为一谈 |
| 民间实践的人类学调查 | 当代六爻/梅花的实际运作 | 研究"人们如何使用术数"，而非"术数是否有效" |

**给学习者的建议**：本知识库把《易》分为三层——**文献层**（经文、传文、出土本）、**技术层**（筮法、纳甲、体用）、**意义层**（哲学、伦理、审美）。三层各有其标准：文献层讲证据，技术层讲规则一致与可复核，意义层讲解释力。**混层论证是易学写作中最常见的失误**，也是本编反复标注"一说"的原因。

## 八、自测题（附答案要点）

**1. 写出乾宫八卦的次序，并说明"游魂""归魂"的生成规则。为什么归魂卦的内卦必与本宫相同？**
答案要点：乾宫：乾为天（本宫）、天风姤（一世）、天山遁（二世）、天地否（三世）、风地观（四世）、山地剥（五世）、火地晋（游魂）、火天大有（归魂）。游魂＝五世卦第四爻再变回；归魂＝游魂卦内卦三爻全部变回本宫。归魂卦的内卦必与本宫相同，因为归魂的定义就是"内卦复归本宫"，故乾宫归魂大有内卦为乾、坎宫归魂师内卦为坎，可逐一验算。

**2. 默写八经卦的纳支（内外卦各三爻），并说明"阳卦顺行、阴卦逆行"具体指什么。**
答案要点：乾：甲子、甲寅、甲辰 / 壬午、壬申、壬戌；坎：戊寅、戊辰、戊午 / 戊申、戊戌、戊子；艮：丙辰、丙午、丙申 / 丙戌、丙子、丙寅；震：庚子、庚寅、庚辰 / 庚午、庚申、庚戌；巽：辛丑、辛亥、辛酉 / 辛未、辛巳、辛卯；离：己卯、己丑、己亥 / 己酉、己未、己巳；坤：乙未、乙巳、乙卯 / 癸丑、癸亥、癸酉；兑：丁巳、丁卯、丁丑 / 丁亥、丁酉、丁未。"顺行"指阳卦（乾震坎艮）地支按子→寅→辰→午→申→戌隔位前进；"逆行"指阴卦（坤巽离兑）按未→巳→卯→丑→亥→酉隔位后退。

**3. 六亲如何由卦宫推出？以坤宫（土）为例，写出金、水、木、火四行各属何亲。**
答案要点：以卦宫五行为"我"，同我者兄弟、我生者子孙、生我者父母、我克者妻财、克我者官鬼。坤宫属土：金为土所生 → 子孙；水为土所克 → 妻财；木克土 → 官鬼；火生土 → 父母；土本身 → 兄弟。

**4. 什么是旬空？戊午日的旬空是哪两支？"真空"与"假空"如何区分？**
答案要点：旬空是六十甲子按旬排列时每旬轮空的两个地支。戊午属甲寅旬（甲寅、乙卯、丙辰、丁巳、戊午……），该旬空子、丑。真空指爻休囚无气又逢空，作"无"论；假空指爻旺相有气而空，或动爻、伏神逢空，出旬、填实（值该支之日）或冲空之时仍可用。区分关键在月建日辰所定的旺衰。

**5. 梅花易数的时间起卦中，"体"与"用"如何确定？为何说"这一步做错则全盘皆错"？**
答案要点：动爻所在之卦为"用"，另一卦为"体"；体代表求测者自身，用代表所问之事。因为全部吉凶判断都建立在"体用五行生克"上（用生体吉、用克体凶等），体卦一旦取反，生克方向随之全反，吉凶结论恰好颠倒。故必须先确认动爻在哪一卦，再定体用，最后才谈互卦、变卦。

> 全编结语：《周易》之难，不在文字古奥，而在**层累**——卜筮记录、占断辞、哲学解释、术数操作四层叠加在同一部书上，彼此并不完全兼容。读《易》的第一步不是"学会算卦"，而是分清自己读的是哪一层。能做到这一点，筮法可学，《易》理可明；做不到，则两失之。
