# 08 学术批判：可证伪性、统计检验、伦理与法律

> 本篇是全套知识库的"刹车系统"。没有它，前面的知识会变成一套自我封闭的信仰；
> 有了它，你才能在**熟练使用**与**清醒评价**之间保持张力。

## 一、划界问题：什么是科学，什么是伪科学

### 1.1 波普尔的可证伪性

波普尔（Karl Popper）提出：一个命题是科学的，当且仅当它**原则上可以被经验反驳**。

- "明天可能下雨也可能不下"——不可证伪，非科学。
- "水在标准大气压下 100°C 沸腾"——可证伪，科学。

**术数的核心困难**：命理断语通常以"可能性""倾向性""某方面有压力"表述，且解释框架可随时调整（"用神取错了""格局看反了""流年还有一层"）。这使得它在**原则上难以被一次性反驳**。

### 1.2 拉卡托斯的"研究纲领"

拉卡托斯（Imre Lakatos）修正波普尔：科学纲领有"硬核"与"保护带"。硬核不可反驳，保护带可以通过辅助假说调整。

术数恰好是典型的"硬核 + 无限保护带"结构：
- 硬核：阴阳五行、干支节律、全息对应。
- 保护带：用神取法、流派差异、心诚则灵、时辰不准、祖坟影响……

保护带越厚，纲领越"退化"。硕士水平的要求是：**能识别自己正在使用哪一层保护带，并诚实承认它在退化。**

### 1.3 库恩的范式

库恩（Thomas Kuhn）的"范式"概念提示我们：术数与现代科学是**两套不可完全通约的范式**。用科学标准要求术数，和用术数标准要求科学，都是范畴错误。承认这一点，才能既不粗暴否定，也不盲目辩护。

## 二、已有的实证检验（综述）

### 2.1 占星术的经典判决实验

- **Carlson, S. (1985). "A double-blind test of astrology." *Nature*, 318, 419–425.**
  设计：让占星家为 28 名被试匹配其星盘与加州心理量表（CPI）剖面。结果：命中率与随机猜测无显著差异。
  意义：这是"双盲 + 预先注册判据 + 顶级期刊"的范式性研究，至今未被有效反驳。

### 2.2 出生时间与人格/命运的流行病学研究

- 出生季节与某些疾病（如精神分裂症、多发性硬化）存在弱关联，但机制是**产前维生素 D、季节性感染、光照**等环境因素，与命理模型无关。
- 出生时间与职业、寿命、婚姻的**大样本研究**（如对瑞典、丹麦登记数据的分析）未发现命理预测所要求的效应量。
- 注意：这类研究检验的是"出生时间→命运"的**总体相关性**，不是"某个命理师断得准不准"。两者需要不同的设计。

### 2.3 风水与环境心理学

风水研究中**可被科学检验的部分**确实存在：
- 坐北朝南 → 采光、日照、冬季保温（北半球）。
- 背山面水 → 防风、防洪、水源、景观。
- 穿堂风、潮湿、通风不良 → 呼吸道疾病、霉菌。
- "路冲""反弓" → 交通事故风险、噪音、隐私暴露。

这些是**环境与健康/安全的真实关联**，但不需要玄空飞星来解释。风水的"合理内核"主要在这一层。

### 2.4 巴纳姆效应

**Forer, B. R. (1949). "The fallacy of personal validation." *Journal of Abnormal and Social Psychology*, 44, 118–123.**
给全班学生同一份"个性化"人格报告，平均评分 4.26/5。这说明：**模糊、双面、普适的描述会被接受为"精准"。**

许多"神准"的命理断语，本质是巴纳姆语句：
> "你外表坚强，内心其实渴望被理解；你有很大潜力，但常因犹豫错失机会；你对亲近的人很宽容，对陌生人保持距离。"

—— 这段话对 90% 的人都"准"。

## 三、如何设计一个诚实的检验

如果你想认真检验某个命理规则，最低标准是：

1. **预先注册**：先写下"若规则为真，应观察到什么"，再收集数据。
2. **明确判据**：把断语转成可判定命题（如"该命局者 30 岁前结婚的概率高于总体 20 个百分点"）。
3. **大样本**：命理断语的效应量通常很小，需要数千样本才有统计功效。
4. **盲法**：断命者不得接触被测者的任何其他信息（照片、语气、职业）。
5. **对照组**：随机生成的假盘、或打乱出生时间。
6. **多重比较校正**：同时检验 100 条规则，必有 5 条在 p<0.05 显著，需 Bonferroni 或 FDR 校正。
7. **独立复现**：换研究者、换样本、换地区重复。
8. **公开数据与代码**。

**可以预期什么**：按现有证据，最可能的结果是"无显著效应"或"效应可由混杂因素解释"。这不是失败，而是**知识**——它告诉你这套符号系统的有效性边界。

## 四、术数"显得准"的机制清单

| 机制 | 说明 | 识别方法 |
|---|---|---|
| 巴纳姆效应 | 普适描述被当作个性化 | 把断语给第三方看，问"像不像你" |
| 冷读 | 从外表、口音、反应中提取信息 | 录音分析：哪些信息是对方先说的 |
| 确认偏误 | 只记准的 | 预测登记簿 |
| 事后归因 | 结果出来后倒推 | 要求事前书面预测 |
| 选择性解释 | 多解中挑一个 | 固定解释规则，不许中途换 |
| 自我实现 | 被告知后行为改变 | 对照实验 |
| 幸存者偏差 | 只看到成功者 | 统计全体求测者 |
| 语言模糊 | "可能""注意""有压力" | 要求量化与时限 |
| 权威暗示 | 祖传、秘传、头衔 | 只看算法与证据 |
| 互动反馈 | 观察对方微表情调整话术 | 盲测 |

## 五、伦理边界

### 5.1 五条不可逾越的红线

1. **医疗**：不得以命理替代诊疗，不得劝人停药、拒医。
2. **投资**：不得以命理指导股票、期货、加密资产买卖。
3. **人身安全**：不得预言死亡、重病、灾祸并以此收费"化解"（涉嫌恐吓与诈骗）。
4. **他人自主**：不得以命理强迫他人结婚、离婚、堕胎、辞职。
5. **未成年人**：不得对未成年人作负面命运断言。

### 5.2 中国法律环境（概要，非法律意见）

> 时效提示：本法条部分按通俗理解概括，**条文序号与处罚幅度以现行文本为准**。《治安管理处罚法》已于 2025 年修订、2026 年 1 月 1 日起施行，条文序号相较旧法有调整；引用具体条款前请核对现行官方文本。

- 《治安管理处罚法》：利用迷信活动扰乱社会秩序、骗取财物，可受处罚。
- 《刑法》：以非法占有为目的、虚构事实骗取财物，可能构成诈骗罪。
- 《广告法》：不得含有迷信内容；"改运""开光"类宣传易触线。
- 《互联网信息服务管理办法》等：网络内容合规要求。
- 殡葬、建筑、宗教活动另有专门法规（如《殡葬管理条例》）。

> 结论：以**文化研究、民俗展示、娱乐体验**定位的活动空间较大；以**收费预测、灾祸化解、医疗建议**定位的活动风险极高。

### 5.3 学术伦理

- 引用古籍注明版本；引用现代研究注明出处。
- 不伪造"古人原话"来支撑自己的观点（这是术数写作最常见的学术不端）。
- 区分"我认为""某派认为""史料记载"三种陈述。
- 对访谈对象、求测者匿名化处理。

## 六、建设性的研究立场

批判不是目的，**定位**才是。术数在当代至少有四重合法身份：

1. **文化遗产**：易学是中国哲学、数学史、天文学史、民俗学的重要对象。
2. **符号系统**：一套高度形式化的类比推理系统，可研究其结构、逻辑与修辞。
3. **心理现象**：为什么人会相信？巴纳姆效应、控制感需求、不确定性焦虑的缓解。
4. **社会实践**：风水、择日深刻影响了中国传统建筑、聚落、墓葬形态，是建筑史与考古学的实证对象。

**硕士论文级的提问方式**，不是"八字准不准"，而是：

- 清代《协纪辨方书》如何建构"吉日"的知识权威？
- 玄空飞星在民国上海的传播与城市化有何关系？
- 命理话语中的性别建构如何反映社会变迁？
- 风水观念如何影响徽州民居的空间组织？

这些问题**可研究、可证伪、有史料**，且不需要你先相信术数。

## 七、一个自我欺骗的拆解示范

**情境**：某人 2023 年失业，命理师说"你 2023 年流年冲提纲，必主工作变动，幸有贵人化解"。

拆解：

1. **事前性**：这句话是在失业**之后**说的 → 事后归因。
2. **不可证伪**："必主工作变动"——2023 年没失业也可以说"变动的是心态/岗位内容"。
3. **保护带**："幸有贵人化解"——若结果更糟，可说"贵人力量不够"；若结果尚可，可说"贵人应验"。
4. **基础率**：2023 年青年失业率本身较高，任何同龄人都有相当概率失业 → 忽略基础率。
5. **选择性记忆**：记住了这次"准"，忘了几十次"某年必有大变"却无事发生。

**结论**：这个断语的信息量为零。它不是预测，是**事后叙事**。
