# 07 算法实现与排盘规格

> 本篇把"排盘"从口诀变成**可复现的算法**。凡是本篇给出的公式，都应能被独立程序验证。
> 原则：**能算的不要背，要背的必须能给出来源。**

## 一、输入规格

任何排盘系统的输入必须包含：

| 字段 | 说明 | 常见错误 |
|---|---|---|
| 出生/起课时刻 | 精确到分钟（奇门、六壬需精确到时辰甚至刻） | 只给"农历生日" |
| 公历/农历 | 必须标明，且注明是否闰月 | 混用导致月柱错 |
| 出生地经度、纬度 | 经度用于真太阳时，纬度用于日出日没、时区 | 只给城市名不查经度 |
| 时区与夏令时 | 1986–1991 中国夏令时须回退 1 小时 | 忽略 DST |
| 性别 | 决定大运顺逆、紫微大限顺逆、命卦 | — |
| 是否使用真太阳时 | 命理界有争议，须在输出中声明采用哪种 | 不声明 |

### 1.1 真太阳时换算

```
LST = 标准时 + (λ − λ₀) × 4 min/deg + EoT
```

- λ 为当地经度，λ₀ 为时区标准经线（北京时间用 120°E）。
- EoT 为均时差，全年约 −14.2 ~ +16.4 分钟，可用近似式：
  `EoT(分钟) ≈ 9.87·sin(2B) − 7.53·cos(B) − 1.5·sin(B)`，其中 `B = 360°(N−81)/364`，N 为一年中的日序（1 月 1 日 = 1）。本式在 1998 年 365 天全扫实测最大误差 1.42 分钟，见 02a 2.6。
  更精确的 NOAA 分数年近似（iztro / ziwei-doushu 采用）：
  `EoT ≈ 229.18·(0.000075 + 0.001868·cos γ − 0.032077·sin γ − 0.014615·cos 2γ − 0.040849·sin 2γ)`，
  `γ = 2π/365·(N − 1 + (h − 12)/24)`（闰年分母取 366，h 为 24 小时制小时数）。
  两式在 1998 年 365 天全扫相差不超过 1.5 分钟，NOAA 式自身误差约 0.1 分钟；判定时辰边界时优先用 NOAA 式。
- 结论：乌鲁木齐（87.6°E）与北京时间差约 −130 分钟，足以跨越一个时辰。

## 二、历法核心算法

### 2.1 儒略日（JD）与干支日

```
JD(公历 Y-M-D 12:00 UT) 用标准算法（Fliegel–Van Flandern）：
a = floor((14 − M)/12)
y = Y + 4800 − a
m = M + 12a − 3
JDN = D + floor((153m+2)/5) + 365y + floor(y/4) − floor(y/100) + floor(y/400) − 32045
```

**干支日**：

```
index = (JDN + 49) mod 60     # 结果 0..59 对应 甲子..癸亥
```

> 注：上式要求 JDN 为整数（整日）；若改用含小数的儒略日，须先取整（floor）再代入，否则常数 +49 会差 1。

验证锚点（务必写进单元测试）：

| 日期 | 干支日 |
|---|---|
| 1900-01-01 | 甲戌 |
| 1949-10-01 | 甲子 |
| 2000-01-01 | 戊午 |

> 注意：术数以**子初换日**（23:00）还是**子正换日**（00:00）有流派差异；六爻、奇门多用子初换日，八字有"早晚子时"两派。程序必须把该开关暴露给用户。

### 2.2 节气与太阳黄经

节气本质是太阳视黄经达到 15° 的整数倍。工程上有三种精度档：

1. **查表法**：使用天文年历（寿星天文历、Swiss Ephemeris）的节气时刻表，精度到秒，推荐。
2. **低精度解析式**（适合教学）：用太阳平黄经 + 中心差近似，误差可达数分钟，临界生日会出错。
3. **VSOP87/DE 星历**：高精度，成本高。

**关键**：立春、惊蛰等"节"的**交接时刻**决定年柱、月柱。若出生时刻在交节前后数分钟，必须用高精度数据，并声明所用星历。

> 注：本篇只给三档方法，不内置节气表；实际交付必须声明所用星历（查表档需写明星历版本与来源），并注意不同聚合源之间可差十余分钟。

### 2.3 年柱、月柱

- 年柱：以**立春**时刻为界。立春前属上一年干支。
- 月柱：以十二"节"为界（立春→寅月，惊蛰→卯月，……小寒→丑月）。
- 月干用**五虎遁**：

```
寅月天干 = f(年干)：甲己→丙，乙庚→戊，丙辛→庚，丁壬→壬，戊癸→甲
其余月份天干顺推
```

即：甲己之年丙作首（丙寅月），乙庚之岁戊为头（戊寅月），丙辛必定寻庚起（庚寅月），丁壬壬位顺行流（壬寅月），若问戊癸何方发，甲寅之上好追求（甲寅月）。

- 月支固定：寅卯辰巳午未申酉戌亥子丑 对应 1–12 月（节气月）。

### 2.4 时柱（五鼠遁）

```
时干 = f(日干)：甲己→甲，乙庚→丙，丙辛→戊，丁壬→庚，戊癸→壬   （子时天干）
其余时辰顺推
```

口诀：甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途。

时支：子 23–01、丑 01–03、寅 03–05、卯 05–07、辰 07–09、巳 09–11、午 11–13、未 13–15、申 15–17、酉 17–19、戌 19–21、亥 21–23。

## 三、八字大运算法

### 3.1 顺逆

- 阳年男、阴年女 → **顺排**（月柱之后的下一个干支开始）。
- 阴年男、阳年女 → **逆排**（月柱之前的一个干支开始）。

### 3.2 起运岁数

1. 顺排：算出生时刻到**下一个节**的时间差；逆排：算出生时刻到**上一个节**的时间差。
2. 折算：**三日折一年，一日折四月，一时辰（2 小时）折十天**。
3. 精确式：`起运年数 = 差值总分钟数 / (3×24×60)`，余数再按比例折算月、日。

```
例：顺排，出生后 47 天 8 小时到下一节
47 天 → 47/3 = 15 年余 2 天
2 天 → 2×4 = 8 个月
8 小时 → 8/2×10 = 40 天 ≈ 1 个月 10 天
起运 ≈ 15 岁 9 个月 10 天
```

### 3.3 交运与流年

- 交运时刻 = 出生时刻 + 起运精确时长，之后每 10 年换一步大运。
- 流年以立春为界。
- 常见互动：岁运并临、天克地冲、伏吟反吟、三合三会成局、填实、透干。

## 四、紫微斗数安星算法（可编程版）

### 4.1 定命宫、身宫

以**寅宫为 1**，正月起寅：

```
命宫 = 寅 + (生月 − 1) − (生时支序号)   （地支序号：子=0,丑=1,…,亥=11，模 12）
身宫 = 寅 + (生月 − 1) + (生时支序号)
```

直觉：从寅顺数到生月，再从该宫起子时**逆**数到生时定命宫；身宫则**顺**数。

### 4.2 定十二宫

命宫确定后，逆时针（子→亥→戌…方向即地支逆行）依次安：命、兄弟、夫妻、子女、财帛、疾厄、迁移、交友（仆役）、官禄、田宅、福德、父母。

### 4.3 定五行局

1. 用**五虎遁**由年干定寅宫天干（甲己→丙寅，乙庚→戊寅，丙辛→庚寅，丁壬→壬寅，戊癸→甲寅）。
2. 顺推得命宫天干。
3. 取命宫干支的**纳音五行**，得局数：

| 纳音五行 | 局 | 起限岁 |
|---|---|---|
| 水 | 水二局 | 2–11 |
| 木 | 木三局 | 3–12 |
| 金 | 金四局 | 4–13 |
| 土 | 土五局 | 5–14 |
| 火 | 火六局 | 6–15 |

### 4.4 紫微星定位（核心算法）

设生日为 d（农历日），局数为 n（2/3/4/5/6）。以**寅宫为起点**：

```
q = ceil(d / n)
r = q * n − d          # 补足到整局的差额，0 ≤ r < n
base = 寅 + (q − 1)     # 商数从寅宫起顺数
if r 为偶数: 紫微 = base + r   （顺数）
if r 为奇数: 紫微 = base − r   （逆数）
```

**验算（用"六五四三二，酉午亥辰丑"这一通行初一表核对）**：

| 局 n | d=1 时 q,r | 计算 | 结果 | 口诀表 |
|---|---|---|---|---|
| 水二 | q=1,r=1 | 寅−1 | 丑 | 丑 ✓ |
| 木三 | q=1,r=2 | 寅+2 | 辰 | 辰 ✓ |
| 金四 | q=1,r=3 | 寅−3 | 亥 | 亥 ✓ |
| 土五 | q=1,r=4 | 寅+4 | 午 | 午 ✓ |
| 火六 | q=1,r=5 | 寅−5 | 酉 | 酉 ✓ |

### 4.5 天府与十四主星

- **天府**：与紫微关于**寅—申轴**对称。以地支序号（子=0…亥=11）表示：
  `天府 = (4 − 紫微) mod 12`
  验：紫微在寅（2）→ 天府在寅；紫微在子（0）→ 天府在辰（4）；紫微在申（8）→ 天府在申。
- **紫微系（逆布）**：紫微 → 天机（紫微逆 1）→ 太阳（天机逆 2）→ 武曲（太阳逆 1）→ 天同（武曲逆 1）→ 廉贞（天同逆 3）。
- **天府系（顺布，以天府为 0）**：天府 → 太阴（顺 1）→ 贪狼（顺 2）→ 巨门（顺 3）→ 天相（顺 4）→ 天梁（顺 5）→ 七杀（顺 6）→ 破军（七杀顺 4）。

**验算**：紫微在子时，应得 天机亥、太阳酉、武曲申、天同未、廉贞辰、天府辰、太阴巳、贪狼午、巨门未、天相申、天梁酉、七杀戌、破军寅。此为传世"紫微在子"标准盘，可作单元测试。

### 4.7 大限

- 起限：`起限岁 = 局数`，每限 10 年。

- 流年：以流年地支所在宫为流年命宫；小限另有起法；斗君用于流月。

### 6.2 飞星轨迹（洛书次序）

五入中顺飞的元旦盘：

```
巽4  离9  坤2
震3  中5  兑7
艮8  坎1  乾6
```

飞星路径恒为：**中 → 乾 → 兑 → 艮 → 离 → 坎 → 坤 → 震 → 巽**，数字序列 5→6→7→8→9→1→2→3→4（顺飞）；逆飞反序。

运星盘：以当运数入中，按上述路径飞布，各宫得数 = `（元旦盘数 − 5 + 运数）mod 9`（0 记 9）。

### 6.3 山星与向星

1. 取坐山所在宫的**运星数**，入中宫，按顺/逆飞布 → **山星盘**（主人丁）。
2. 取向首所在宫的**运星数**，入中宫，按顺/逆飞布 → **向星盘**（主财禄）。
3. 顺逆由该山所属**三元龙**的阴阳决定：阳顺阴逆。

三元龙分组（二十四山）：

| 元龙 | 八山 |
|---|---|
| 天元龙 | 子、午、卯、酉、乾、巽、艮、坤 |
| 人元龙 | 寅、申、巳、亥、乙、辛、丁、癸 |
| 地元龙 | 辰、戌、丑、未、甲、庚、壬、丙 |

> **重要提醒**：二十四山的具体阴阳配属，玄空各家（沈氏玄空、无常派、中州派等）与三合派的"净阴净阳"并不相同，且三合盘与三元盘阴阳表也不同。**本篇不给出单一定论**，请以所采用流派的原书表格为准，并注明出处。详见 05b 篇。
> 自检方法：**结构约束 + 已知格局反推**。
> ① 结构约束：天元龙八山分两组，子午卯酉必同阴阳、乾坤艮巽必同阴阳（人元、地元同理分组）。任何把子与午判成相反阴阳的表，都与三元龙分组自相矛盾。
> ② 反推校验：以"八运子山午向为**旺山旺向**"（山星 8 到坐山坎宫、向星 8 到向首离宫）为约束检验所用阴阳表。按通行表（子午卯酉俱阴），子、午皆阴逆飞，得山星盘与向星盘后恰为旺山旺向；若某表算出"离宫山 8 向 8"的双星会向，则该表把子、午判成了一阳一阴，表有误（详见 09 卷二第 4 题）。

### 6.4 四大格局判定

| 格局 | 判据 |
|---|---|
| 旺山旺向 | 山星旺星到坐山，向星旺星到向首 |
| 上山下水 | 山星旺星到向首，向星旺星到坐山 |
| 双星会向 | 山、向旺星俱到向首 |
| 双星会坐 | 山、向旺星俱到坐山 |

另需检查：入囚（旺星入中宫受困）、五黄、七星打劫、替卦（兼向超出一定度数时用替卦）、年月日时紫白的叠加。

## 七、八宅命卦算法

```
1900–1999 出生：男 = (100 − yy) mod 9；女 = (yy − 4) mod 9
2000–2099 出生：男 = (99 − yy) mod 9；女 = (yy + 6) mod 9
余数 0 记作 9；余数 5：男寄坤(2)，女寄艮(8)
```

其中 yy 为年份后两位，年界按**立春**。

命卦数→卦：1坎、2坤、3震、4巽、6乾、7兑、8艮、9离。

验算：1980 男 = 20 mod 9 = 2 → 坤二；1990 男 = 10 mod 9 = 1 → 坎一；2000 男 = 99 mod 9 = 0 → 九离；1980 女 = 76 mod 9 = 4 → 巽四。

### 8.2 单元测试清单（建议逐条实现）

1. 干支日锚点：1900-01-01=甲戌；1949-10-01=甲子；2000-01-01=戊午。
2. 立春边界：某年立春前后各 1 分钟的八字年柱应不同。
3. 五虎遁、五鼠遁全表 60 组自洽（月干、时干可由年干、日干唯一推出）。
4. 大运起运：顺逆各 3 例，手工与程序一致。
5. 紫微：五个局 × 初一至三十，与通行"紫微定位表"逐格比对。
6. 紫微：紫微在子 → 十四主星位置与标准盘一致。
7. 纳甲：六十四卦三百八十四爻装干支，与纳甲表逐爻比对。
8. 玄空：以流派原书给出的 10 个案例盘反测。
9. 真太阳时：乌鲁木齐（87.6°E）地方时应比北京时间**晚**约 2 小时 10 分（即地方时读数 = 北京时间 − 2h10m）。
10. 闰月：闰月出生者的月柱只由节气决定，与闰月无关（八字）；紫微斗数则存在闰月归属流派差异，须单列开关。
11. 晚子时四档规则（23:00 换日 / 00:00 换日 / 日柱当日+时干次日 / 日时柱全当日）各给 1 例，输出必须标注所用口径。
12. 闰月四口径（归本月 / 归次月 / 半月切 / 按节气）对同一天各出一盘，差异可复现且每盘标注。
13. 真太阳时：同一钟表时刻在 87.6°E 与 120°E 的时辰归属不同；NOAA 式与 9.87 式在 1998 年全扫差 < 2 分钟。
