# 00 治学总论：如何以学术态度研究术数

> 本篇回答三个问题：术数是什么？该怎么研究它？怎样才算"硕士程度"？
> 这是整套知识库的**方法论宪法**。后续所有断语、案例、评价，都必须遵守本篇立下的规矩。

---

## 一、术数在中国传统知识体系中的位置

### 1.1 《汉书·艺文志》的"术数略"

班固将天下图书分为六略，其中"术数略"下分六种：

| 类别 | 内容 | 现代对应 |
|---|---|---|
| 天文 | 星象、日月五星、二十八宿 | 天文学史 |
| 历谱 | 历法、年谱、世系 | 历法史、年代学 |
| 五行 | 阴阳五行、干支、刑德、堪舆 | 术数主体（八字、风水等） |
| 蓍龟 | 龟卜、蓍筮 | 占卜、易学 |
| 杂占 | 梦占、物候、灾异 | 民俗信仰 |
| 形法 | 相地、相人、相物 | 风水、相术 |

**关键认知**：在古代，术数与天文历法同属"数术"，是**当时的知识前沿**，不是今天意义上的"迷信"或"娱乐"。它的许多技术成分（历法计算、天文观测、地理勘察）后来分化成了现代科学；它的占验成分则没有通过现代检验。研究术数，必须先承认这个"同源分化"的历史事实。

### 1.2 术数的三层结构

任何一门术数都可以拆成三层，研究时必须分层处理：

1. **技术层**（可计算、可验证）：排盘算法、历法换算、罗盘测量、卦爻装纳。**这一层有对错，必须精确。**
2. **象义层**（符号解释）：十神象义、星曜庙旺、卦爻辞义、砂水吉凶。**这一层是约定与传承，有流派差异。**
3. **推断层**（经验断言）：断某人某年升迁、某宅某年破财。**这一层是经验命题，必须接受检验。**

初学者常犯的错误是：把技术层的精确性（"我排盘排对了"）误当作推断层的有效性（"所以我断得准"）。**排盘正确只是必要条件，不是充分条件，更不是有效性证明。**

## 二、硕士层次的三条标准

"硕士程度"在本知识库里被操作化为三条可检验的标准：

### 标准一：能精确复现

- 给出生辰，能手工（或写代码）排出四柱、大运、紫微十二宫、六爻卦盘、玄空飞星盘，**结果可被第三方独立验证**。
- 知道每一个口诀的**适用条件与例外**，而不是背口诀。

### 标准二：能说明来源与分歧

- 每个核心概念能说出：出自哪部书、哪个流派、有何异说。
- 例：庚干四化，中州派作"太阳、武曲、太阴、天同"，全书派作"太阳、武曲、天府、天同"——**能指出分歧并说明各自依据**，而不是假装只有一个答案。

### 标准三：能批判性定位

- 能区分：系统内部自洽 ≠ 外部有效。
- 能指出该术数的**可证伪性缺口**、**已知的认知偏差**、**伦理与法律边界**。
- 能回答："如果它不准，为什么还有那么多人信？如果它准，为什么通不过双盲检验？"

> 三条标准缺一不可。只会排盘是技工；只会批判是不懂装懂；两者兼备才是研究者。

## 三、研究方法

### 3.1 文献学方法

- **版本意识**：同一本书的不同版本可能内容差异巨大（如《紫微斗数全书》与《全集》）。引用时必须注明版本。
- **托名问题**：术数古籍大量托名古人（《葬书》托郭璞、《紫微斗数全书》托陈抟、《滴天髓》托刘基）。托名不等于无价值，但**不能当作史料直接使用**。
- **层累造成**：古籍往往是历代增补的结果，要区分"原书"与"注疏"。
- **一手材料优先**：能用原文就不用二手转述；无法核对原文时，明确标注"转引"。

### 3.2 内证与外证

- **内证**：在术数系统内部检验其一致性（如用已知命例验证排盘算法、检查表格是否自洽）。
- **外证**：用系统外部证据检验其有效性（统计、双盲实验、历史档案比对）。
- **硕士训练要求**：内证必须做扎实；外证必须诚实面对结果。

### 3.3 历史语境化

- 术数命题的含义随时代变化。如"官"在八字中主贵，是科举社会的产物；现代社会"官"的对应物已变。
- 用现代概念直接套古代术语（如把"财"直接等同于"财富"）是常见误解。

## 四、必须警惕的六种认知偏差

| 偏差 | 在术数中的表现 | 纠治方法 |
|---|---|---|
| 确认偏误 | 只记住断准的，忘掉断错的 | 建立预测登记簿，事前记录、事后核对 |
| 事后归因 | 事情发生后倒推命理原因 | 只承认事前可检验的预测 |
| 巴纳姆效应 | "你外表坚强内心敏感"式断语人人适用 | 要求断语具体、可反驳 |
| 幸存者偏差 | 只看到"大师"的成功案例 | 统计分母：所有求测者而非成名者 |
| 事后选择 | 从多种解释中挑一个吻合的 | 事前固定解释框架 |
| 权威光环 | "祖传""秘传""某大师弟子" | 看算法与证据，不看头衔 |

**实践工具：预测登记簿（prediction ledger）**

任何一次"推断"都按以下格式记录：日期、对象、依据（盘面+规则）、预测内容（具体到可判定）、置信度、实际结果、复盘。这是把术数从"信仰"变成"可研究现象"的最小装置。

## 五、术数系统内部有效性的来源

为什么术数能让人感到"准"？学术上有几种解释，硕士层次应当都了解：

1. **冷读术（cold reading）**：通过观察、语言诱导获取信息，再以"算出来"的形式反馈。
2. **福勒效应**：模糊、双面、普适的描述被接受为"精准"。
3. **自我实现预言**：被告知"今年不利"者行为趋于保守，结果真的"不利"。
4. **选择性记忆与传播**：准的案例被口耳相传，不准的被遗忘。
5. **符号系统的解释弹性**：同一盘面可作多种解释，总有一种事后吻合（"解释学上的过度适应"）。
6. **真实存在的弱相关**：出生季节与某些疾病/性格特质有流行病学关联（如冬季出生与某些风险），但这与命理模型无关，属混杂因素。

> 注意：以上解释**不否定术数作为文化现象的价值**，只是否定其作为预测技术的有效性。二者可以并存。

## 六、伦理与法律边界（概要，详见 08 篇）

- 不用于**医疗诊断或替代治疗**（可能延误病情）。
- 不用于**投资决策**（可能造成财产损失）。
- 不用于**婚姻强制、生育选择、就业歧视**（侵犯他人自主权）。
- 不进行**恐吓式营销**（"你有血光之灾，需付费化解"涉嫌诈骗）。
- 涉及**殡葬、建筑、宗教活动**时遵守现行法规。
- 学术引用与公开传播时，注明"民俗文化研究"性质，不宣称科学有效性。

## 七、本知识库的学科地图

```
易学研究/
├── 00 治学总论（本篇）          ← 方法论
├── 01 基础：阴阳五行干支历法      ← 公理层
├── 02 八字命理（子平术）         ← 命理 A
├── 03 紫微斗数                  ← 命理 B
├── 04 周易卦象与筮法             ← 占卜
├── 05 风水堪舆                  ← 环境
├── 06 择日/奇门/六壬等旁支        ← 应用与旁支
├── 07 算法实现与排盘规格          ← 技术层
├── 08 学术批判、统计检验、伦理法律  ← 反思层
├── 09 硕士水平综合自测卷          ← 考核
└── 10 术语总表与索引             ← 工具
```

**学习路径建议**：

1. 先读 01（基础）与 07（算法），把"排盘"这件事做对。
2. 再选一门主修（02 或 03 或 04 或 05），其余作通识。
3. 读完主修后读 08，给整个体系"装上刹车"。
4. 用 09 自测，暴露薄弱环节。
5. 长期：建立自己的案例库与预测登记簿。

## 八、必读书目（分层次）

**通论与学术史**

- 李零《中国方术正考》《中国方术续考》（中华书局）——术数研究的现代学术奠基之作。
- 李零《〈孙子〉古本研究》等可作方法论参考。
- 江晓原《天学真原》《星占学与传统文化》——天文与占卜关系的科学史研究。
- 顾颉刚《秦汉的方士与儒生》——托名与层累问题的经典示范。

**易学**

- 高亨《周易古经今注》《周易大传今注》。
- 黄寿祺、张善文《周易译注》。
- 朱熹《周易本义》。
- 王弼《周易注》（楼宇烈校释）。

**命理**

- 《渊海子平》《三命通会》《滴天髓》（任铁樵注）《子平真诠》《穷通宝鉴》。
- 韦千里《千里命稿》、徐乐吾《子平真诠评注》。

**紫微**

- 《紫微斗数全书》《紫微斗数全集》。
- 王亭之《中州派紫微斗数》。
- 陆斌兆《紫微斗数讲义》。

**风水**

- 《葬书》《撼龙经》《疑龙经》《雪心赋》《地理五诀》。
- 蒋大鸿《地理辨正》、沈竹礽《沈氏玄空学》。
- 王其亨等《风水理论研究》（建筑学界的重要论文集）。

**择日与三式**

- 《协纪辨方书》《六壬大全》《烟波钓叟歌》。

> 读书法：先读**原典**，再读**注本**，最后读**现代研究**。切忌只读现代"大师"的通俗书——它们往往是二手转述加个人发挥。
