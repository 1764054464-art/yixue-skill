## 怎么用

- 提到八字、紫微、六爻、风水、择日、批语，或要求排盘、复算、解释术语、判断说法真假时，模型会加载它。
- 它默认只读 1–3 份 reference，不整库倾倒。
- 输出会带"盘 → 校验 → 分级断语 → 建议 → 免责"的结构。

## 自检

```powershell
python scripts/verify.py
```

Windows 若 `python` 是应用商店空壳（退出码 9009），用 DSH 捆绑的解释器：

```powershell
C:\Users\PC\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe scripts\verify.py
```

预期输出 `全部 PASS / 0 FAIL`（条数以脚本输出为准）。改动 references 里的任何表格后都应重跑。

## 边界（写进 SKILL.md，也写在这里）

- 可复算的部分（干支、排盘、卦序、纳甲、飞星）是可靠的；断事效度**不可自评**，术数预测无同行评审证据支持。
- 文献层依据通行学界说法，未做原典校勘；分歧处标"一说"。全库严格直引仅 2 处，其余为转述，**不能当引文引用**。
- 玄空二十四山阴阳采用通行三元龙表；其他流派表不同，换表结论会变（已知并已标注）。
- 庚干四化、子时换日、起运折算、城门替卦等均有流派分歧，已标两说。
- 定位：**文化研究与方法演示**，不替代医疗、法律、投资意见；不收费预测，不做灾祸化解。
